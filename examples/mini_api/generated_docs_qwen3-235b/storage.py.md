# Модуль `storage.py`


Модуль обеспечивает простое хранилище на основе памяти с возможностью нормализации email-адресов для согласованного хранения.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Простое хранилище в памяти для демонстрационных целей.

#### Методы

##### `__init__() -> None`

Инициализирует пустое хранилище в памяти с начальным значением следующего идентификатора, равным 1.

**Побочные эффекты:**

Инициализирует внутреннее состояние объекта: создает пустой словарь _data для хранения данных и устанавливает _next_id в 1.

**Примеры:**

Создание нового экземпляра хранилища в памяти.

```python
storage = InMemoryStorage()
```

##### `create(payload: dict[str, Any]) -> int`

Создает новый элемент в хранилище с уникальным идентификатором и сохраняет переданные данные.

**Параметры:**

- `payload` (`dict[str, Any]`) — Словарь с данными, которые необходимо сохранить в хранилище

**Возвращаемое значение:**

- `int` — Уникальный идентификатор созданного элемента

**Побочные эффекты:**

Увеличивает внутренний счетчик _next_id и изменяет состояние словаря _data, добавляя новый элемент.

**Примеры:**

Создание элемента в хранилище.

```python
storage.create({'name': 'test', 'value': 42})
```

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает элемент из хранилища по указанному идентификатору или None, если элемент не найден.

**Параметры:**

- `item_id` (`int`) — Идентификатор элемента, который необходимо получить из хранилища

**Возвращаемое значение:**

- `dict[str, Any] | None` — Словарь с данными элемента, если элемент найден; иначе None

**Граничные случаи:**

Если item_id отсутствует в хранилище, метод возвращает None.

**Примеры:**

Получение элемента по существующему идентификатору.

```python
storage.get(1)
```

Попытка получить элемент по несуществующему идентификатору.

```python
storage.get(999)
```

## Функции

### `def normalize_email(email: str) -> str`

Нормализует email для хранения.

**Параметры:**

- `email` (`str`) — email-адрес, который необходимо нормализовать

**Возвращаемое значение:**

- `str` — нормализованный email-адрес в нижнем регистре без пробелов в начале и в конце

**Примеры:**

Нормализация email с пробелами и в верхнем регистре.

```python
normalize_email('  Example@Email.com  ')
```
