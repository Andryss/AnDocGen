# Модуль `storage.py`


Модуль обеспечивает простое хранилище в памяти и утилиту для нормализации email-адресов.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Простое хранилище в памяти для демонстрационных целей.

#### Методы

##### `__init__() -> None`

Инициализирует пустое хранилище в памяти с начальным значением следующего идентификатора, равным 1.

**Побочные эффекты:**

Инициализирует два приватных атрибута: _data как пустой словарь для хранения данных и _next_id как счётчик следующего доступного идентификатора.

##### `create(payload: dict[str, Any]) -> int`

Создает новый элемент в хранилище с уникальным идентификатором и сохраняет переданные данные.

**Параметры:**

- `payload` (`dict[str, Any]`) — словарь с данными, которые необходимо сохранить в хранилище

**Возвращаемое значение:**

- `int` — уникальный идентификатор созданного элемента

**Побочные эффекты:**

Увеличивает внутренний счётчик _next_id и добавляет новую запись в словарь _data.

**Примеры:**

item_id = storage.create({'name': 'example', 'value': 42})

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает элемент из хранилища по его идентификатору или None, если элемент не найден.

**Параметры:**

- `item_id` (`int`) — Идентификатор элемента, который необходимо получить из хранилища

**Возвращаемое значение:**

- `dict[str, Any] | None` — Словарь с данными элемента, если элемент найден; иначе None

**Граничные случаи:**

Если item_id отсутствует в хранилище, метод возвращает None.

## Функции

### `def normalize_email(email: str) -> str`

Нормализует email для хранения.

**Параметры:**

- `email` (`str`) — email-адрес, который необходимо нормализовать

**Возвращаемое значение:**

- `str` — нормализованный email-адрес в нижнем регистре без пробелов по краям

**Примеры:**

normalize_email('  Example@Domain.COM  ') вернёт 'example@domain.com'
