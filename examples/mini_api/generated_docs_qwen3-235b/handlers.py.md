### `class UserHandler`

Обрабатывает операции API, связанные с пользователями.

#### Методы

##### `__init__(storage: InMemoryStorage) -> None`

Инициализирует обработчик пользователей с указанным хранилищем.

**Параметры:**

- `storage` (`InMemoryStorage`) — экземпляр хранилища в памяти для управления данными пользователей

**Побочные эффекты:**

Присваивает переданное хранилище приватному атрибуту экземпляра.

**Примеры:**

Создание обработчика пользователей с хранилищем в памяти.

```python
storage = InMemoryStorage()
handler = UserHandler(storage)
```

**Смотрите также:**

InMemoryStorage

##### `get_user(user_id: int) -> ApiResponse`

Получает пользователя по его идентификатору из внутреннего хранилища. Если пользователь не найден, возвращает ответ с кодом 404, иначе возвращает данные пользователя с кодом 200.

**Параметры:**

- `user_id` (`int`) — Уникальный идентификатор пользователя, который необходимо получить

**Возвращаемое значение:**

- `ApiResponse` — Объект ответа, содержащий статус и тело. При успехе — статус 200 и данные пользователя; при отсутствии — статус 404 и сообщение об ошибке

**Граничные случаи:**

Случай, когда user_id существует, но соответствующий пользователь был удалён или не сохранялся — обрабатывается корректно (возвращается 404).

**Примеры:**

Получение существующего пользователя.

```python
handler.get_user(123)
```

Попытка получить несуществующего пользователя.

```python
handler.get_user(999)
```

**Смотрите также:**

InMemoryStorage — хранилище, используемое для получения данных пользователя; ApiResponse — тип возвращаемого значения

##### `create_user(name: str, email: str) -> ApiResponse`

Создает нового пользователя с заданным именем и email, сохраняет его в хранилище и возвращает ответ с идентификатором пользователя.

**Параметры:**

- `name` (`str`) — имя пользователя
- `email` (`str`) — email пользователя, который будет нормализован перед сохранением

**Возвращаемое значение:**

- `ApiResponse` — объект ответа с кодом состояния 201 и телом, содержащим идентификатор созданного пользователя

**Побочные эффекты:**

Сохраняет данные пользователя в хранилище, что может повлиять на состояние приложения между запросами.

**Примеры:**

Создание нового пользователя с именем и email.

```python
handler.create_user("Иван Иванов", "ivan@example.com")
```

**Смотрите также:**

normalize_email — функция нормализации email; InMemoryStorage — хранилище, используемое для сохранения данных пользователя
