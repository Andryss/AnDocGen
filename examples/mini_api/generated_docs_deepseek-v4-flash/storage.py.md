# Модуль `storage.py`


Модуль хранилища ключ-значение в памяти, предназначенный для демонстрационных целей. Предоставляет функцию нормализации адресов электронной почты и класс простого хранилища данных в памяти.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Класс для простого хранения данных в памяти, предназначенный для демонстрационных целей.

**Назначение:**

Обеспечивает базовое хранилище данных в оперативной памяти с возможностью создания новых записей и получения их по уникальному идентификатору.

**Использование:**

Создайте экземпляр класса InMemoryStorage, затем используйте метод create для добавления новой записи (он вернёт присвоенный идентификатор) и метод get для извлечения записи по этому идентификатору. Хранилище не является постоянным и теряет данные при завершении работы программы.

#### Методы

##### `__init__() -> None`

Инициализирует новый экземпляр хранилища InMemoryStorage, создавая пустую внутреннюю структуру данных и сбрасывая счётчик идентификаторов.

**Возвращаемое значение:**

- `None` — метод не возвращает значения

**Побочные эффекты:**

Инициализирует внутреннее состояние экземпляра: создаёт пустой словарь _data (отображение целочисленных идентификаторов на словари с данными) и устанавливает счётчик _next_id в значение 1.

**Примеры:**

Создать новый экземпляр хранилища.

```python
storage = InMemoryStorage()
```

##### `create(payload: dict[str, Any]) -> int`

Создаёт новую запись в хранилище, присваивая ей уникальный идентификатор, и возвращает этот идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — данные, которые будут сохранены в хранилище

**Возвращаемое значение:**

- `int` — уникальный идентификатор созданной записи

**Побочные эффекты:**

Увеличивает внутренний счётчик _next_id на единицу и сохраняет переданные данные в хранилище _data под ключом item_id.

**Примеры:**

Создать запись с данными.

```python
create({"name": "example"})
```

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает элемент из внутреннего хранилища по его идентификатору.

**Параметры:**

- `item_id` (`int`) — идентификатор элемента, который требуется получить из хранилища

**Возвращаемое значение:**

- `dict[str, Any] | None` — словарь с данными элемента, если элемент с указанным идентификатором существует, иначе None

**Граничные случаи:**

Если элемента с указанным идентификатором нет в хранилище, метод возвращает None.

**Примеры:**

Получить элемент с идентификатором 1.

```python
storage.get(1)
```

## Функции

### `def normalize_email(email: str) -> str`

Нормализует адрес электронной почты для хранения: удаляет ведущие и завершающие пробелы и приводит строку к нижнему регистру.

**Параметры:**

- `email` (`str`) — адрес электронной почты, который требуется нормализовать

**Возвращаемое значение:**

- `str` — нормализованный адрес электронной почты без ведущих и завершающих пробелов, в нижнем регистре

**Граничные случаи:**

Пустая строка возвращает пустую строку. Строка, состоящая только из пробелов, возвращает пустую строку. Все символы переводятся в нижний регистр, ведущие и завершающие пробелы удаляются.

**Примеры:**

Нормализовать адрес с пробелами и заглавными буквами.

```python
normalize_email('  User@Example.COM  ')
```

Нормализовать адрес, уже находящийся в нижнем регистре без пробелов.

```python
normalize_email('user@example.com')
```
