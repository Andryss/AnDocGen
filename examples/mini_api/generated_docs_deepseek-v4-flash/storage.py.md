## Классы

### `class InMemoryStorage`

Простое хранилище в памяти для демонстрационных целей.

#### Методы

##### `__init__() -> None`

Инициализирует новый экземпляр хранилища InMemoryStorage, создавая пустую внутреннюю структуру данных и счётчик идентификаторов.

**Возвращаемое значение:**

- `None` — Метод ничего не возвращает.

**Побочные эффекты:**

Инициализирует атрибуты экземпляра: _data (пустой словарь) и _next_id (равный 1).

**Примеры:**

Создание экземпляра хранилища.

```python
storage = InMemoryStorage()
```

##### `create(payload: dict[str, Any]) -> int`

Создаёт новую запись в хранилище, присваивая ей уникальный целочисленный идентификатор, и возвращает этот идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — произвольные данные, которые необходимо сохранить в хранилище

**Возвращаемое значение:**

- `int` — уникальный идентификатор созданной записи

**Побочные эффекты:**

Изменяет внутреннее состояние хранилища: увеличивает счётчик идентификаторов и добавляет переданные данные во внутренний словарь.

**Примеры:**

Создать запись с простыми данными.

```python
storage.create({"name": "example"})
```

Создать несколько записей и получить последовательные идентификаторы.

```python
first_id = storage.create({"a": 1})
second_id = storage.create({"b": 2})
```

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает элемент из хранилища по его идентификатору. Если элемент с указанным идентификатором отсутствует, возвращает None.

**Параметры:**

- `item_id` (`int`) — идентификатор элемента, который требуется получить

**Возвращаемое значение:**

- `dict[str, Any] | None` — данные элемента, соответствующие идентификатору, или None, если элемент не найден

**Граничные случаи:**

Если элемент с указанным идентификатором отсутствует в хранилище, метод возвращает None. Если ключ присутствует, но его значение равно None, метод также вернёт None, что неотличимо от отсутствия ключа.

**Примеры:**

Получить элемент с идентификатором 1.

```python
storage.get(1)
```

## Функции

### `def normalize_email(email: str) -> str`

Нормализует адрес электронной почты для хранения: удаляет ведущие и завершающие пробельные символы и приводит все символы к нижнему регистру.

**Параметры:**

- `email` (`str`) — адрес электронной почты, который требуется нормализовать

**Возвращаемое значение:**

- `str` — нормализованный адрес электронной почты без ведущих и завершающих пробелов, в нижнем регистре

**Граничные случаи:**

Пустая строка возвращает пустую строку. Строка, состоящая только из пробельных символов, возвращает пустую строку. Символы в верхнем регистре приводятся к нижнему регистру.

**Примеры:**

Нормализовать адрес с пробелами и заглавными буквами.

```python
normalize_email('  User@Example.COM  ')
```

Нормализовать уже нормализованный адрес.

```python
normalize_email('user@example.com')
```
