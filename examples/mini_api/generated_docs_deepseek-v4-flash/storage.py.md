# Модуль `storage.py`


Модуль хранилища ключ-значение в памяти, предназначенный для демонстрационных целей. Предоставляет функцию нормализации адресов электронной почты и класс простого хранения данных в памяти.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Класс для простого хранения данных в памяти, предназначенный для демонстрационных целей.

#### Методы

##### `create(payload: dict[str, Any]) -> int`

Создаёт новую запись в хранилище, присваивая ей уникальный целочисленный идентификатор, и возвращает этот идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — произвольные данные, которые будут сохранены в хранилище под новым идентификатором

**Возвращаемое значение:**

- `int` — уникальный идентификатор созданной записи

**Побочные эффекты:**

Изменяет внутреннее состояние хранилища: увеличивает счётчик следующего идентификатора и добавляет запись во внутренний словарь данных.

**Примеры:**

storage = InMemoryStorage()
id1 = storage.create({"name": "item1"})  # id1 = 0
id2 = storage.create({"name": "item2"})  # id2 = 1

##### `__init__() -> None`

Инициализирует новый экземпляр хранилища InMemoryStorage, создавая пустое внутреннее хранилище и устанавливая начальный идентификатор.

**Побочные эффекты:**

Инициализирует внутренние атрибуты: _data (пустой словарь) и _next_id (равный 1).

**Примеры:**

storage = InMemoryStorage()

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает элемент хранилища по его идентификатору.

**Параметры:**

- `item_id` (`int`) — идентификатор элемента, который требуется получить

**Возвращаемое значение:**

- `dict[str, Any] | None` — словарь с данными элемента, если он существует, иначе None

**Граничные случаи:**

Если элемент с указанным идентификатором отсутствует в хранилище, возвращается None.

**Примеры:**

storage = InMemoryStorage()
result = storage.get(42)

## Функции

### `def normalize_email(email: str) -> str`

Нормализует адрес электронной почты для хранения: удаляет пробельные символы по краям и приводит все буквы к нижнему регистру.

**Параметры:**

- `email` (`str`) — исходный адрес электронной почты

**Возвращаемое значение:**

- `str` — нормализованный адрес электронной почты в нижнем регистре без ведущих и завершающих пробелов

**Граничные случаи:**

Пустая строка или строка, состоящая только из пробелов, возвращает пустую строку. Регистр всех букв приводится к нижнему.

**Побочные эффекты:**

Нет.

**Примеры:**

normalize_email('  User@Example.COM ') → 'user@example.com'
