# Модуль `handlers.py`


Модуль обработчиков API в стиле HTTP (упрощённый пример). Предоставляет классы для представления ответов API и обработки операций, связанных с пользователями.

**Содержание:**

- [Классы](#классы)

## Классы

### `class ApiResponse`

Класс для представления ответа API в виде структурированного объекта данных.

**Назначение:**

Обеспечивает единообразный формат ответов API, инкапсулируя данные ответа и связанную информацию.

**Использование:**

Используется для создания объектов ответа API при обработке запросов в модуле handlers.py. Точные поля и поведение зависят от реализации класса.

**Поля:**

- `status` (`int`) — —
- `body` (`dict[str, Any]`) — —

### `class UserHandler`

Класс для обработки операций API, связанных с пользователями.

**Назначение:**

Инкапсулирует логику обработки запросов API для получения и создания пользователей, используя хранилище в памяти.

**Использование:**

Создайте экземпляр класса, передав объект InMemoryStorage в конструктор, затем вызывайте методы get_user и create_user для выполнения операций с пользователями.

#### Методы

##### `__init__(storage: InMemoryStorage) -> None`

Инициализирует экземпляр обработчика пользователей, сохраняя переданное хранилище в приватный атрибут.

**Параметры:**

- `storage` (`InMemoryStorage`) — хранилище данных, используемое обработчиком

**Побочные эффекты:**

Сохраняет переданное хранилище в приватный атрибут _storage экземпляра.

**Примеры:**

Создание обработчика пользователей с хранилищем в памяти.

```python
storage = InMemoryStorage()
handler = UserHandler(storage)
```

##### `get_user(user_id: int) -> ApiResponse`

Возвращает пользователя по его идентификатору из хранилища в виде ответа API.

**Параметры:**

- `user_id` (`int`) — идентификатор пользователя, которого требуется получить

**Возвращаемое значение:**

- `ApiResponse` — объект ответа API: при успешном поиске — статус 200 и данные пользователя в теле ответа; если пользователь не найден — статус 404 и тело {"error": "not found"}

**Граничные случаи:**

Если пользователь с указанным идентификатором отсутствует в хранилище, метод возвращает ответ со статусом 404 и телом {"error": "not found"}.

**Примеры:**

Получить пользователя по идентификатору 42.

```python
handler.get_user(42)
```

##### `create_user(name: str, email: str) -> ApiResponse`

Создаёт нового пользователя в хранилище и возвращает ответ с идентификатором созданного пользователя.

**Параметры:**

- `name` (`str`) — Имя пользователя.
- `email` (`str`) — Адрес электронной почты пользователя.

**Возвращаемое значение:**

- `ApiResponse` — Объект ответа со статусом 201 и телом {"id": user_id}, где user_id — идентификатор созданного пользователя.

**Граничные случаи:**

Адрес электронной почты нормализуется перед сохранением: удаляются ведущие и завершающие пробелы, строка приводится к нижнему регистру.

**Побочные эффекты:**

Создаёт запись пользователя в хранилище.

**Примеры:**

Создать пользователя с именем Alice и адресом alice@example.com.

```python
handler.create_user('Alice', 'alice@example.com')
```

**Смотрите также:**

Связанная сущность: normalize_email(email) — нормализует адрес электронной почты.
