### `class UserHandler`

Обработчик операций API, связанных с пользователями.

#### Методы

##### `get_user(user_id: int) -> ApiResponse`

Возвращает данные пользователя по его идентификатору.

**Параметры:**

- `user_id` (`int`) — идентификатор пользователя

**Возвращаемое значение:**

- `ApiResponse` — ответ API: при успехе — статус 200 и данные пользователя, при отсутствии — статус 404 и сообщение об ошибке

**Граничные случаи:**

Если пользователь с указанным идентификатором не найден, возвращается ответ со статусом 404 и телом {"error": "not found"}.

**Примеры:**

handler.get_user(42)

**Смотрите также:**

ApiResponse, InMemoryStorage

##### `__init__(storage: InMemoryStorage) -> None`

Конструктор класса UserHandler, сохраняющий переданное хранилище для дальнейшего использования.

**Параметры:**

- `storage` (`InMemoryStorage`) — Объект хранилища данных, который будет использоваться обработчиком.

**Побочные эффекты:**

Присваивает переданный объект storage внутреннему атрибуту _storage.

**Примеры:**

storage = InMemoryStorage()
handler = UserHandler(storage)

##### `create_user(name: str, email: str) -> ApiResponse`

Создаёт нового пользователя в хранилище и возвращает ответ API с идентификатором созданного пользователя.

**Параметры:**

- `name` (`str`) — имя пользователя
- `email` (`str`) — адрес электронной почты пользователя

**Возвращаемое значение:**

- `ApiResponse` — Объект ответа API со статусом 201 и телом, содержащим идентификатор созданного пользователя в поле 'id'.

**Побочные эффекты:**

Создаёт запись пользователя в хранилище (self._storage) с нормализованным адресом электронной почты.

**Примеры:**

user_handler.create_user('Иван', 'ivan@example.com')
