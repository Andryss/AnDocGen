### `class UserHandler`

Класс для обработки операций API, связанных с пользователями.

#### Методы

##### `__init__(storage: InMemoryStorage) -> None`

Инициализирует экземпляр UserHandler, сохраняя переданное хранилище для последующего использования.

**Параметры:**

- `storage` (`InMemoryStorage`) — Объект хранилища, который будет использоваться обработчиком для операций с пользователями.

**Возвращаемое значение:**

- `None` — Метод ничего не возвращает.

**Побочные эффекты:**

Сохраняет ссылку на переданный объект storage в атрибуте экземпляра _storage.

**Примеры:**

Создание экземпляра UserHandler с хранилищем.

```python
storage = InMemoryStorage()
handler = UserHandler(storage)
```

##### `get_user(user_id: int) -> ApiResponse`

Возвращает данные пользователя по его идентификатору. Если пользователь не найден, возвращает ответ с кодом 404.

**Параметры:**

- `user_id` (`int`) — уникальный идентификатор пользователя

**Возвращаемое значение:**

- `ApiResponse` — объект ответа API: при успехе — статус 200 и данные пользователя, при отсутствии пользователя — статус 404 и сообщение об ошибке

**Граничные случаи:**

Если пользователь с указанным user_id не существует в хранилище, возвращается ответ со статусом 404 и телом {"error": "not found"}.

**Примеры:**

Получить существующего пользователя.

```python
handler.get_user(42)
```

Получить несуществующего пользователя.

```python
handler.get_user(999)
```

##### `create_user(name: str, email: str) -> ApiResponse`

Создаёт нового пользователя: нормализует адрес электронной почты, сохраняет запись в хранилище и возвращает ответ с кодом 201 и идентификатором созданного пользователя.

**Параметры:**

- `name` (`str`) — имя пользователя
- `email` (`str`) — адрес электронной почты пользователя; перед сохранением нормализуется функцией normalize_email

**Возвращаемое значение:**

- `ApiResponse` — объект ответа со статусом 201 и телом, содержащим поле id — идентификатор созданного пользователя

**Граничные случаи:**

Если переданный email содержит ведущие/завершающие пробелы или символы в верхнем регистре, они будут нормализованы перед сохранением; это может повлиять на уникальность адреса в хранилище.

**Побочные эффекты:**

Добавляет новую запись пользователя в хранилище self._storage.

**Примеры:**

Создать пользователя с именем и адресом электронной почты.

```python
handler.create_user(name="Иван", email=" Ivan@Example.COM ")
```

**Смотрите также:**

normalize_email — функция, используемая для нормализации адреса электронной почты перед сохранением.
