# mini_api

Документация проекта, сгенерированная AnDocGen.

## Корневые модули

| Модуль | Описание |
|--------|--------------|
| [__init__.py](__init__.py.md) | Пакет мини-примера API. |
| [handlers.py](handlers.py.md) | Модуль обработчиков API в стиле HTTP (упрощённый пример). |
| [storage.py](storage.py.md) | Модуль хранилища ключ-значение в памяти, предназначенный для демонстрационных целей. Предоставляет функцию нормализации адресов электронной почты и класс простого хранения данных в памяти. |
