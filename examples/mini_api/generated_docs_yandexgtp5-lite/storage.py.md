# Модуль `storage.py`


Модуль для хранения данных в памяти с функциями нормализации email и класса для демонстрационного хранения данных.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Класс для простого хранения данных в памяти для демонстрационных целей.

#### Методы

##### `__init__() -> None`

Инициализирует объект InMemoryStorage, устанавливая начальные значения для внутренних переменных.

**Возвращаемое значение:**

- `None` — None

**Примеры:**

Инициализация InMemoryStorage

```python
InMemoryStorage().__init__()
```

##### `create(payload: dict[str, Any]) -> int`

Создаёт элемент в хранилище и возвращает его идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — Словарь с данными для сохранения

**Возвращаемое значение:**

- `int` — Идентификатор созданного элемента

**Примеры:**

Создать элемент в хранилище

```python
InMemoryStorage.create({'key': 'value'})
```

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает словарь с данными элемента по его идентификатору или None, если элемент не найден.

**Параметры:**

- `item_id` (`int`) — идентификатор элемента

**Возвращаемое значение:**

- `dict[str, Any] | None` — словарь с данными элемента или None, если элемент не найден

**Примеры:**

Получить данные по идентификатору

```python
InMemoryStorage.get(item_id)
```

## Функции

### `def normalize_email(email: str) -> str`

Приводит адрес электронной почты к нижнему регистру и убирает лишние пробелы для хранения.

**Параметры:**

- `email` (`str`) — строка для нормализации

**Возвращаемое значение:**

- `str` — нормализованный адрес электронной почты

**Примеры:**

Привести адрес электронной почты к нижнему регистру и убрать лишние пробелы.

```python
normalize_email('User@example.com')
```
