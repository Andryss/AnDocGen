# Модуль `storage.py`


Модуль хранения данных в памяти с функциями нормализации адресов электронной почты.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Класс InMemoryStorage предназначен для хранения данных в памяти компьютера.

**Назначение:**

Простое хранилище в памяти для демонстрационных целей.

**Использование:**

Используйте метод __init__ для инициализации объекта класса. Метод get позволяет получить данные по указанному идентификатору item_id. Метод create создаёт элемент в хранилище и возвращает его идентификатор.

#### Методы

##### `__init__() -> None`

Инициализирует объект класса InMemoryStorage, устанавливая начальные значения для внутренних переменных.

**Возвращаемое значение:**

- `None` — None

**Примеры:**

Инициализация класса InMemoryStorage

```python
self._data: dict[int, dict[str, Any]] = {}; self._next_id = 1
```

##### `create(payload: dict[str, Any]) -> int`

Создаёт элемент в хранилище и возвращает его идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — Данные для сохранения в хранилище

**Возвращаемое значение:**

- `int` — Идентификатор созданного элемента

**Примеры:**

Создать элемент в хранилище

```python
InMemoryStorage.create({'key': 'value'})
```

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает данные по указанному идентификатору item_id

**Параметры:**

- `item_id` (`int`) — Получить данные по указанному идентификатору

**Возвращаемое значение:**

- `dict[str, Any] | None` — Возвращает данные по item_id в виде словаря или None, если данных нет

**Примеры:**

Получить данные по item_id

```python
InMemoryStorage.get(item_id=1)
```

## Функции

### `def normalize_email(email: str) -> str`

Приводит адрес электронной почты к нижнему регистру и удаляет начальные и конечные пробелы для хранения.

**Параметры:**

- `email` (`str`) — Адрес электронной почты для нормализации

**Возвращаемое значение:**

- `str` — Нормализованный адрес электронной почты

**Примеры:**

Привести адрес электронной почты к нижнему регистру и удалить начальные и конечные пробелы.

```python
normalize_email('  user@example.com  ')
```
