# Модуль `storage.py`


Модуль, реализующий простое в памяти хранилище с нормализацией адресов электронной почты.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Простое в памяти хранилище для демонстрационных целей.

#### Методы

##### `__init__() -> None`

Инициализирует новый экземпляр InMemoryStorage.

**Побочные эффекты:**

Создает пустой словарь для хранения данных и задает начальное значение следующего ID.

##### `create(payload: dict[str, Any]) -> int`

Создает новый элемент в хранилище и возвращает его уникальный ID.

**Параметры:**

- `payload` (`dict[str, Any]`) — данные для нового элемента

**Возвращаемое значение:**

- `int` — уникальный ID созданного элемента

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает данные из в памяти хранилища по заданному идентификатору.

**Параметры:**

- `item_id` (`int`) — идентификатор элемента

**Возвращаемое значение:**

- `dict[str, Any] | None` — словарь с данными или None, если элемент не найден

## Функции

### `def normalize_email(email: str) -> str`

Нормализует адрес электронной почты для хранения.

**Параметры:**

- `email` (`str`) — адрес электронной почты

**Возвращаемое значение:**

- `str` — нормированный адрес электронной почты

**Примеры:**

normalize_email(' Example@Email.com ') вернет 'example@email.com'
