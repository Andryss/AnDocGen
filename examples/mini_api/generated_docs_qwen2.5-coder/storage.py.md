# Модуль `storage.py`


Модуль в памяти для хранения данных с нормализацией электронной почты.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Класс для простого in-memory хранилища с демонстрационными целями.

#### Методы

##### `__init__() -> None`

Инициализирует объект InMemoryStorage с пустым словарем для хранения данных и начальным значением для следующего ID.

**Примеры:**

Создать новый объект InMemoryStorage.

```python
storage = InMemoryStorage()
```

##### `create(payload: dict[str, Any]) -> int`

Создает новый элемент в хранилище и возвращает его идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — Данные для нового элемента

**Возвращаемое значение:**

- `int` — Идентификатор созданного элемента

**Примеры:**

Создать новый элемент в хранилище.

```python
create({'name': 'example', 'value': 42})
```

##### `get(item_id: int) -> dict[str, Any] | None`

Получает данные по идентификатору элемента из встроенной памяти.

**Параметры:**

- `item_id` (`int`) — идентификатор элемента, данные которого нужно получить

**Возвращаемое значение:**

- `dict[str, Any] | None` — словарь данных по идентификатору или None, если элемент не найден

**Примеры:**

Получить данные по идентификатору.

```python
storage.get(1)
```

## Функции

### `def normalize_email(email: str) -> str`

Нормализует электронную почту для хранения.

**Параметры:**

- `email` (`str`) — Электронная почта для нормализации.

**Возвращаемое значение:**

- `str` — Нормализованная электронная почта.

**Примеры:**

Нормализовать электронную почту.

```python
normalize_email(' Example@Email.COM ')
```
