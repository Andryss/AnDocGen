# Модуль `storage.py`


Модуль для работы с in-memory key-value хранилищем.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Простое встроенное хранилище данных для демонстрационных целей.

**Назначение:**

Инкапсулирует логику работы с данными в объектном интерфейсе, храня их в оперативной памяти.

**Использование:**

Создайте экземпляр класса InMemoryStorage и используйте методы для взаимодействия с хранилищем.

#### Методы

##### `__init__() -> None`

Инициализирует экземпляр InMemoryStorage.

**Примеры:**

Создать новый экземпляр InMemoryStorage.

```python
storage = InMemoryStorage()
```

##### `create(payload: dict[str, Any]) -> int`

Создает новый элемент в хранилище и возвращает его уникальный идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — словарь данных для создания нового элемента в хранилище.

**Возвращаемое значение:**

- `int` — уникальный идентификатор созданного элемента.

**Побочные эффекты:**

Нет побочных эффектов.

**Примеры:**

Создать новый элемент в хранилище с данными {'name': 'example', 'value': 123}.

```python
item_id = storage.InMemoryStorage.create({'name': 'example', 'value': 123})
```

##### `get(item_id: int) -> dict[str, Any] | None`

Получает данные из хранилища по идентификатору.

**Параметры:**

- `item_id` (`int`) — идентификатор объекта для получения данных from storage.py.

**Возвращаемое значение:**

- `dict[str, Any] | None` — словарь с данными по идентификатору или None, если данные не найдены.

**Примеры:**

Получить данные объекта по идентификатору.

```python
storage.get(123)
```

## Функции

### `def normalize_email(email: str) -> str`

Нормализует адрес электронной почты для хранения.

**Параметры:**

- `email` (`str`) — адрес электронной почты для нормализации.

**Возвращаемое значение:**

- `str` — нормированный адрес электронной почты.

**Примеры:**

Нормализация адреса электронной почты.

```python
normalize_email(' Example@Email.com ')
```
