# Модуль `handlers.py`


Модуль с обработчиками HTTP-like API и классом для представления ответов.

**Содержание:**

- [Классы](#классы)

## Классы

### `class ApiResponse`

Класс для представления ответов API.

**Назначение:**

Используется для формирования и возвращения данных клиентам через API.

**Использование:**

Создайте экземпляр класса с необходимыми данными и используйте его для отправки ответа.

**Поля:**

- `status` (`int`) — —
- `body` (`dict[str, Any]`) — —

### `class UserHandler`

Класс для управления пользователями.

**Назначение:**

Обеспечивает методы для получения и создания пользователей через API.

**Использование:**

Создайте экземпляр класса UserHandler с объектом хранилища и вызывайте методы для выполнения операций с пользователями.

#### Методы

##### `__init__(storage: InMemoryStorage) -> None`

Инициализирует экземпляр класса UserHandler с объектом хранилища.

**Параметры:**

- `storage` (`InMemoryStorage`) — Объект хранилища, используемый для хранения данных пользователей.

**Примеры:**

Создать экземпляр UserHandler с объектом хранилища.

```python
handler = UserHandler(InMemoryStorage())
```

##### `get_user(user_id: int) -> ApiResponse`

Получает пользователя по его ID.

**Параметры:**

- `user_id` (`int`) — ID пользователя, который нужно получить.

**Возвращаемое значение:**

- `ApiResponse` — Ответ с пользователем или ошибкой.

**Примеры:**

Получить пользователя по ID.

```python
user_handler.get_user(123)
```

##### `create_user(name: str, email: str) -> ApiResponse`

Создает нового пользователя и возвращает его ID.

**Параметры:**

- `name` (`str`) — имя пользователя для создания:
- `email` (`str`) — адрес электронной почты для пользователя:

**Возвращаемое значение:**

- `ApiResponse` — ответ сервера с HTTP-статусом 201 и телом {'id': user_id}

**Примеры:**

Создать пользователя с указанными имя и email.

```python
user_handler = UserHandler(storage=InMemoryStorage())
response = user_handler.create_user(name='John Doe', email='john.doe@example.com')
```
