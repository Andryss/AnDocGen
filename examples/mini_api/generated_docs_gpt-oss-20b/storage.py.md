## Классы

### `class InMemoryStorage`

Класс InMemoryStorage реализует простое хранение данных в памяти, позволяющее создавать, получать и хранить элементы по уникальному идентификатору.

#### Методы

##### `__init__() -> None`

Инициализирует объект InMemoryStorage, создавая пустой словарь для хранения данных и устанавливая начальный идентификатор.

**Побочные эффекты:**

Инициализирует внутренние структуры хранения данных и счётчик идентификаторов.

**Примеры:**

storage = InMemoryStorage()

##### `create(payload: dict[str, Any]) -> int`

Создаёт новый элемент в памяти и возвращает его уникальный идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — Словарь с данными, которые будут сохранены.

**Возвращаемое значение:**

- `int` — Уникальный идентификатор созданного элемента.

**Побочные эффекты:**

Изменяет внутреннее состояние: увеличивает счётчик _next_id и добавляет элемент в словарь _data.

**Примеры:**

storage = InMemoryStorage()
new_id = storage.create({'name': 'Alice', 'age': 30})
print(new_id)  # → 0

**Смотрите также:**

InMemoryStorage

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает элемент из памяти по его идентификатору.

**Параметры:**

- `item_id` (`int`) — Идентификатор запрашиваемого элемента

**Возвращаемое значение:**

- `dict[str, Any] | None` — Словарь, представляющий элемент, либо None, если элемент не найден

**Примеры:**

storage = InMemoryStorage()
storage._data = {1: {"name": "item1"}, 2: {"name": "item2"}}
print(storage.get(1))  # {'name': 'item1'}
print(storage.get(3))  # None

## Функции

### `def normalize_email(email: str) -> str`

Функция нормализует адрес электронной почты для хранения.

**Параметры:**

- `email` (`str`) — строка с адресом электронной почты

**Возвращаемое значение:**

- `str` — нормализованный адрес электронной почты

**Примеры:**

normalize_email('  USER@Example.COM  ') -> 'user@example.com'
normalize_email('Test@Domain.org') -> 'test@domain.org'
