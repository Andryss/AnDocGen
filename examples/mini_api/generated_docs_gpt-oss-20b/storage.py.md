- [Классы](#классы)

## Классы

### `class InMemoryStorage`

Класс InMemoryStorage обеспечивает простое хранение данных в памяти для демонстрационных целей.

**Назначение:**

Позволяет сохранять, получать и создавать элементы, используя уникальные идентификаторы.

**Использование:**

Создайте экземпляр класса, используйте методы get и create для работы с данными. Идентификатор генерируется автоматически при создании.

#### Методы

##### `__init__() -> None`

Инициализирует объект InMemoryStorage, создавая пустой словарь для хранения данных и устанавливая начальный идентификатор.

**Примеры:**

Создание экземпляра InMemoryStorage.

```python
storage = InMemoryStorage()
```

##### `create(payload: dict[str, Any]) -> int`

Создаёт новый элемент в памяти и возвращает его уникальный идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — Пакет данных, который будет сохранён в хранилище.

**Возвращаемое значение:**

- `int` — Уникальный идентификатор созданного элемента.

**Побочные эффекты:**

Изменяет внутреннее состояние хранилища, добавляя новый элемент.

**Примеры:**

Создать новый элемент в памяти.

```python
storage = InMemoryStorage()
item_id = storage.create({"name": "example", "value": 42})
print(item_id)
```

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает элемент из внутреннего словаря по заданному идентификатору.

**Параметры:**

- `item_id` (`int`) — Идентификатор запрашиваемого элемента

**Возвращаемое значение:**

- `dict[str, Any] | None` — Словарь элемента, если найден, иначе None

**Примеры:**

Получить элемент из InMemoryStorage

```python
storage = InMemoryStorage()
storage._data = {1: {'name': 'example'}}
item = storage.get(1)
print(item)  # {'name': 'example'}
missing = storage.get(2)
print(missing)  # None
```

## Функции

### `def normalize_email(email: str) -> str`

Нормализует email для хранения.

**Параметры:**

- `email` (`str`) — строка с email

**Возвращаемое значение:**

- `str` — нормализованный email

**Примеры:**

Нормализовать email.

```python
normalize_email('  Example@Domain.COM  ')
```
