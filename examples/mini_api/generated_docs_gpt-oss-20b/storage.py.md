# Модуль `storage.py`


Модуль storage.py предоставляет простое в памяти хранилище ключ-значение и функцию нормализации адресов электронной почты.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class InMemoryStorage`

Класс InMemoryStorage реализует простое хранение данных в памяти, предоставляя методы инициализации, получения и создания элементов с уникальными идентификаторами.

#### Методы

##### `__init__() -> None`

Инициализирует объект InMemoryStorage, создавая пустой словарь для хранения данных и устанавливая следующий идентификатор в 1.

**Возвращаемое значение:**

- `None` — Метод не возвращает значения.

**Побочные эффекты:**

Создает атрибуты _data и _next_id, которые используются для хранения данных и генерации уникальных идентификаторов.

**Примеры:**

Создание экземпляра InMemoryStorage.

```python
storage = InMemoryStorage()
```

##### `create(payload: dict[str, Any]) -> int`

Создаёт новый элемент в памяти, присваивая ему уникальный идентификатор.

**Параметры:**

- `payload` (`dict[str, Any]`) — Словарь с данными, который будет сохранён.

**Возвращаемое значение:**

- `int` — Уникальный идентификатор созданного элемента.

**Побочные эффекты:**

Изменяет внутреннее состояние: увеличивает счётчик _next_id и добавляет payload в словарь _data.

**Примеры:**

Создание элемента в памяти.

```python
storage = InMemoryStorage()
item_id = storage.create({'name': 'example'})
print(item_id)
```

##### `get(item_id: int) -> dict[str, Any] | None`

Возвращает объект из памяти по заданному идентификатору, либо None, если элемент не найден.

**Параметры:**

- `item_id` (`int`) — Уникальный идентификатор запрашиваемого элемента

**Возвращаемое значение:**

- `dict[str, Any] | None` — Словарь, представляющий объект, либо None, если элемент отсутствует

**Примеры:**

Получить элемент из InMemoryStorage.

```python
storage = InMemoryStorage()
storage._data = {1: {'name': 'item', 'value': 42}}
result = storage.get(1)
print(result)  # {'name': 'item', 'value': 42}
print(storage.get(2))  # None
```

## Функции

### `def normalize_email(email: str) -> str`

Нормализует адрес электронной почты для хранения.

**Параметры:**

- `email` (`str`) — строка с адресом электронной почты

**Возвращаемое значение:**

- `str` — нормализованный адрес электронной почты

**Примеры:**

Нормализовать адрес электронной почты с пробелами и заглавными буквами.

```python
normalize_email('  USER@Example.com  ')
```
