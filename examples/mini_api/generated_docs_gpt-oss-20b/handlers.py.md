### `class UserHandler`

Класс, отвечающий за операции с пользователями в API: создание и получение пользователей.

#### Методы

##### `__init__(storage: InMemoryStorage) -> None`

Инициализирует экземпляр UserHandler, сохраняет ссылку на переданное хранилище пользователей.

**Параметры:**

- `storage` (`InMemoryStorage`) — Хранилище пользователей, которое будет использоваться обработчиком.

**Возвращаемое значение:**

- `None` — Метод не возвращает значения.

**Побочные эффекты:**

Сохраняет переданный объект хранилища в атрибуте _storage экземпляра UserHandler.

**Примеры:**

Создание экземпляра UserHandler с использованием InMemoryStorage.

```python
from handlers import UserHandler
from storage import InMemoryStorage

storage = InMemoryStorage()
handler = UserHandler(storage)
```

##### `get_user(user_id: int) -> ApiResponse`

Возвращает пользователя по идентификатору или ошибку 404, если пользователь не найден.

**Параметры:**

- `user_id` (`int`) — Идентификатор пользователя

**Возвращаемое значение:**

- `ApiResponse` — Ответ API с пользователем (статус 200) или ошибкой 404.

**Граничные случаи:**

Если пользователь не найден, возвращается статус 404 с телом {"error": "not found"}.

##### `create_user(name: str, email: str) -> ApiResponse`

Создаёт нового пользователя, нормализует email и сохраняет данные в хранилище, возвращая ответ API с кодом 201 и идентификатором пользователя.

**Параметры:**

- `name` (`str`) — Имя пользователя
- `email` (`str`) — Адрес электронной почты пользователя

**Возвращаемое значение:**

- `ApiResponse` — Ответ API с кодом состояния 201 и телом, содержащим id созданного пользователя

**Побочные эффекты:**

Записывает нового пользователя в хранилище

**Примеры:**

Создание пользователя с нормализацией email

```python
response = handler.create_user("Alice", "Alice+test@example.com")
print(response.status)  # 201
print(response.body)    # {'id': 1}
```
