# Модуль `calculator.py`


Модуль калькулятора с функциями сложения и деления.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class Calculator`

Класс для выполнения базовых арифметических операций.

#### Методы

##### `__init__(precision: int = 2) -> None`

Инициализирует объект класса Calculator с заданной точностью.

**Параметры:**

- `precision` (`int`) — количество знаков после запятой для округления результатов операций

**Примеры:**

Создать объект Calculator с точностью до двух знаков после запятой.

```python
calc = Calculator(precision=2)
```

##### `format_result(value: float) -> str`

Форматирует число с заданной точностью и возвращает его строковое представление.

**Параметры:**

- `value` (`float`) — Число, которое нужно отформатировать

**Возвращаемое значение:**

- `str` — Строковое представление числа с заданной точностью

**Примеры:**

Форматировать число с точностью до двух знаков после запятой.

```python
Calculator.format_result(123.4567)
```

##### `multiply(x: int, y: int) -> int`

Умножает два целых числа и возвращает результат.

**Параметры:**

- `x` (`int`) — первый множитель
- `y` (`int`) — второй множитель

**Возвращаемое значение:**

- `int` — произведение x и y

**Примеры:**

Умножить два целых числа.

```python
multiply(3, 4)
```

## Функции

### `def add(a: float, b: float) -> float`

Складывает два числа и возвращает результат.

**Параметры:**

- `a` (`float`) — первое слагаемое
- `b` (`float`) — второе слагаемое

**Возвращаемое значение:**

- `float` — сумма a и b

**Примеры:**

Сложить два числа.

```python
add(1, 2)
```

### `def divide(a: float, b: float) -> float | None`

Делит первое число на второе и возвращает результат. Если делитель равен нулю, возвращает None.

**Параметры:**

- `a` (`float`) — число, которое нужно разделить
- `b` (`float`) — делитель

**Возвращаемое значение:**

- `float | None` — результат деления или None, если делитель равен нулю

**Граничные случаи:**

Деление на ноль.

**Примеры:**

Разделить 10 на 2.

```python
divide(10, 2)
```

Попытаться разделить 5 на 0 (должно вернуть None).

```python
divide(5, 0)
```
