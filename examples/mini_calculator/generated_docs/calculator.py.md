# Модуль `calculator.py`


Модуль калькулятора с базовыми операциями сложения и деления.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class Calculator`

Класс для базовых арифметических операций.

#### Методы

##### `__init__(precision: int = 2) -> None`

Инициализирует объект Calculator с заданной точностью.

**Параметры:**

- `precision` (`int`) — точность вычислений (по умолчанию 2)

**Примеры:**

calculator = Calculator(precision=3)

##### `format_result(value: float) -> str`

Форматирует число с заданной точностью и возвращает его как строку.

**Параметры:**

- `value` (`float`) — число для форматирования

**Возвращаемое значение:**

- `str` — строка, представляющая число с заданной точностью

##### `multiply(x: int, y: int) -> int`

Умножает два целых числа и возвращает результат.

**Параметры:**

- `x` (`int`) — первый множитель
- `y` (`int`) — второй множитель

**Возвращаемое значение:**

- `int` — произведение x и y

## Функции

### `def add(a: float, b: float) -> float`

Складывает два числа и возвращает результат.

**Параметры:**

- `a` (`float`) — первое слагаемое
- `b` (`float`) — второе слагаемое

**Возвращаемое значение:**

- `float` — сумма a и b

### `def divide(a: float, b: float) -> float | None`

Делит первое число на второе и возвращает результат.

**Параметры:**

- `a` (`float`) — делимое
- `b` (`float`) — делитель

**Возвращаемое значение:**

- `float | None` — результат деления или None, если делитель равен нулю

**Граничные случаи:**

Если делитель равен нулю, функция возвращает None.

**Примеры:**

Примеры использования:

print(divide(10, 2))  # Вывод: 5.0
print(divide(5, 0))   # Вывод: None
