# Модуль `calculator.py`


Модуль калькулятора с базовыми операциями сложения и деления.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class Calculator`

Класс для базовых арифметических операций.

**Назначение:**

Инкапсулирует методы для выполнения умножения и форматирования результатов.

**Использование:**

Создайте экземпляр класса и вызывайте метод multiply для умножения чисел. Результат будет автоматически отформатирован с заданной точностью.

#### Методы

##### `__init__(precision: int = 2) -> None`

Инициализирует объект класса Calculator с заданной точностью.

**Параметры:**

- `precision` (`int`) — точность чисел, по умолчанию 2 знака после запятой

**Побочные эффекты:**

Инициализирует атрибут объекта класса Calculator.

**Примеры:**

Создать экземпляр класса Calculator с точностью 3 знака после запятой.

```python
calc = Calculator(3)
```

##### `format_result(value: float) -> str`

Форматирует результат числа с заданной точностью.

**Параметры:**

- `value` (`float`) — число для форматирования.

**Возвращаемое значение:**

- `str` — строка с отформатированным числом.

**Примеры:**

Форматировать число с точностью до двух знаков после запятой.

```python
Calculator.format_result(123.456789)
```

##### `multiply(x: int, y: int) -> int`

Умножает два числа и возвращает результат.

**Параметры:**

- `x` (`int`) — первый множитель (целое число) для умножения.
- `y` (`int`) — второй множитель (целое число) для умножения.

**Возвращаемое значение:**

- `int` — произведение чисел x и y.

**Примеры:**

Умножить два целых числа.

```python
multiply(3, 4)
```

## Функции

### `def add(a: float, b: float) -> float`

Складывает два числа и возвращает результат.

**Параметры:**

- `a` (`float`) — первое слагаемое, число типа float; required argument; must be present in the call to function 'add'.
- `b` (`float`) — второе слагаемое, число типа float; required argument; must be present in the call to function 'add'.

**Возвращаемое значение:**

- `float` — сумма a и b, число типа float

**Примеры:**

Сложить два числа.

```python
add(1.5, 2.5)
```

### `def divide(a: float, b: float) -> float | None`

Делит два числа и возвращает результат. Если делитель равен нулю, возвращает None.

**Параметры:**

- `a` (`float`) — делимое число (числитель) - любое вещественное число или целое число, которое можно представить как число с плавающей запятой.
- `b` (`float`) — делитель числа (знаменатель) - любое вещественное число или целое число, которое можно представить как число с плавающей запятой. Если b равно нулю, функция возвращает None.

**Возвращаемое значение:**

- `float | None` — результат деления или None, если делитель равен нулю.

**Граничные случаи:**

Функция возвращает None при попытке деления на ноль.

**Побочные эффекты:**

Нет побочных эффектов.

**Примеры:**

Разделить два числа без остатка.

```python
divide(10, 2)
```

Попытаться разделить на ноль (должно вернуть None).

```python
divide(5, 0)
```
