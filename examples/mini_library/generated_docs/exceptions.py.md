# Модуль `exceptions.py`


Модуль исключений для мини-библиотеки.

**Содержание:**

- [Классы](#классы)

## Классы

### `class MiniLibraryError(Exception)`

Базовый класс ошибок для библиотеки.

**Назначение:**

Используется как базовый класс для всех специфических ошибок в библиотеке mini_library.

**Использование:**

Этот класс не должен быть напрямую использован. Вместо этого используются его наследники, которые определены в конкретных модулях библиотеки.

**Наследование:**

- `Exception`

### `class NotFoundError(MiniLibraryError)`

Класс исключения для обозначения отсутствия запрошенной сущности.

**Назначение:**

Используется для сигнализации об ошибке при попытке получить несуществующий ресурс в мини-библиотеке.

**Использование:**

Генерируется, когда запрашиваемая сущность отсутствует. Обрабатывается соответствующим образом для предотвращения дальнейшего выполнения операций.

**Наследование:**

- `MiniLibraryError`

### `class ValidationError(MiniLibraryError)`

Класс исключения для ошибок валидации входных данных.

**Назначение:**

Используется для сигнализации о неверном формате или значении входных данных в приложении mini_library.

**Использование:**

Выбрасывается когда функции или методы получают несоответствующие данные, что указывает на ошибку валидации.

**Наследование:**

- `MiniLibraryError`
