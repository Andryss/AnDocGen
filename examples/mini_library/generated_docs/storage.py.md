# Модуль `storage.py`


Модуль для хранения заказов в процесс-локальном словаре.

**Содержание:**

- [Классы](#классы)

## Классы

### `class InMemoryStorage`

Класс для хранения заказов в процесс-локальном словаре.

**Назначение:**

Инкапсулирует логику работы с заказами в памяти процесса.

**Использование:**

Создайте экземпляр класса и используйте его методы для управления заказами.

#### Методы

##### `__init__() -> None`

Инициализирует экземпляр InMemoryStorage с пустым словарем заказов и начальным значением следующего ID.

**Примеры:**

Инициализировать экземпляр InMemoryStorage.

```python
storage = InMemoryStorage()
```

##### `create(customer: str) -> Order`

Создает новый заказ для указанного клиента и возвращает его.

**Параметры:**

- `customer` (`str`) — имя или ID клиента, для которого создается заказ.

**Возвращаемое значение:**

- `Order` — новый объект заказа

**Примеры:**

Создать новый заказ для клиента 'John Doe'.

```python
order = InMemoryStorage.create('John Doe')
```

##### `list_ids() -> list[int]`

Возвращает отсортированный список идентификаторов заказов.

**Возвращаемое значение:**

- `list[int]` — отсортированный список идентификаторов заказов

**Примеры:**

Получить отсортированный список идентификаторов заказов.

```python
storage.InMemoryStorage().list_ids()
```

##### `get(order_id: int) -> Order`

Получает заказ по его идентификатору.

**Параметры:**

- `order_id` (`int`) — идентификатор заказа, который нужно получить из хранилища в памяти (InMemoryStorage). Этот параметр является обязательным и должен быть целым числом (integer). Он соответствует уникальному номеру заказа в системе мини-библиотеки, который используется для его идентификации и отслеживания. Если указан неверный или несуществующий идентификатор заказа, метод выбросит исключение NotFoundError с сообщением об ошибке, что заказ не найден. Таким образом, этот параметр должен быть предоставлен вызывающим методом при вызове InMemoryStorage.get(). Для получения конкретного заказа необходимо передать его уникальный идентификатор в качестве аргумента для этого метода.

**Возвращаемое значение:**

- `Order` — возвращает объект Order, если заказ с указанным идентификатором существует в хранилище.

**Исключения:**

NotFoundError: выбрасывается, если заказ с указанным идентификатором не найден в хранилище.

**Примеры:**

Получить заказ по его идентификатору.

```python
storage = InMemoryStorage()
order = storage.get(123)
```
