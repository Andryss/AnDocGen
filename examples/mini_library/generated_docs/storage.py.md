# Модуль `storage.py`


Модуль для хранения заказов в памяти процесса.

**Содержание:**

- [Классы](#классы)

## Классы

### `class InMemoryStorage`

Класс для хранения заказов в памяти процесса.

#### Методы

##### `__init__() -> None`

Инициализирует экземпляр в памяти для хранения заказов.

**Побочные эффекты:**

Создает пустой словарь для хранения заказов и устанавливает начальное значение ID равным 1.

**Примеры:**

Инициализировать экземпляр в памяти для хранения заказов.

```python
storage = InMemoryStorage()
```

##### `create(customer: str) -> Order`

Создает новый заказ для указанного клиента и возвращает его.

**Параметры:**

- `customer` (`str`) — Имя клиента

**Возвращаемое значение:**

- `Order` — Созданный заказ

**Примеры:**

Создать заказ для клиента 'John Doe'.

```python
storage.InMemoryStorage.create('John Doe')
```

##### `list_ids() -> list[int]`

Возвращает отсортированный список идентификаторов заказов.

**Возвращаемое значение:**

- `list[int]` — отсортированный список идентификаторов заказов

**Примеры:**

Получить отсортированный список идентификаторов заказов.

```python
storage.InMemoryStorage.list_ids()
```

##### `get(order_id: int) -> Order`

Получает заказ по идентификатору и возвращает его.

**Параметры:**

- `order_id` (`int`) — идентификатор заказа

**Возвращаемое значение:**

- `Order` — заказ, соответствующий идентификатору

**Исключения:**

NotFoundError: если заказ с указанным идентификатором не найден

**Примеры:**

Получить заказ по идентификатору.

```python
storage = InMemoryStorage()
order = storage.get(123)
```
