## Функции

### `def format_items(*labels: str) -> str`

Объединяет переменное количество меток элементов.

**Параметры:**

- `*labels` (`str`) — —

**Возвращаемое значение:**

- `str` — объединенная строка меток элементов

**Примеры:**

Объединить две метки без разделителя.

```python
format_items('item1', 'item2')
```

Объединить три метки с использованием тире в качестве разделителя.

```python
format_items('item1', 'item2', 'item3'), separator='-'
```

### `def format_price(amount: float, currency: str = 'USD') -> str`

Форматирует денежную сумму с символом валюты.

**Параметры:**

- `amount` (`float`) — Сумма для форматирования в виде числа без знака валюты и запятых в дробной части (например, 1234.56). Значение по умолчанию - 0.00 USD если не указано значение параметра currency. Ожидается значение типа float или подобное ему, которое можно преобразовать в число с двумя знаками после запятой для точности до копейки или цента (например, '1234' автоматически приведется к '1234.00'). В случае ошибочного значения параметра amount будет выброшено исключение ValueError. Не должно быть значений типа str или других типов, которые не могут быть преобразованы в число с двумя знаками после запятой, иначе возникнет ошибка при вызове функции format_price(). Не должен содержать символа валюты в значении параметра amount. Если значение параметра currency не указано или равно None, будет использовано значение по умолчанию 'USD'. В случае ошибочного значения параметра currency выбрасывается исключение ValueError. Поддерживаются только следующие значения параметра currency: USD (американская долларовая), EUR (европейская юань), GBP (английский фунт стерлингов) и RUB (русский рубль). В случае ошибочного значения параметра currency выбрасывается исключение ValueError. Не должно быть значений типа str или других типов, которые не могут быть преобразованы в строку с двумя знаками после запятой для точности до копейки или цента (например, '1234' автоматически приведется к '1234.00'). В случае ошибочного значения параметра currency выбрасывается исключение ValueError. Если значение параметра currency равно None, будет использовано значение по умолчанию 'USD'. В случае ошибочного значения параметра currency выбрасывается исключение ValueError.
- `currency` (`str`) — Валюта в формате ISO-4217 (например, 'USD', 'EUR', 'GBP', 'RUB'). Значение по умолчанию - 'USD'. Допустимые значения: USD, EUR, GBP, RUB. Ожидается значение типа str или подобное ему, которое можно преобразовать в строку с двумя знаками после запятой для точности до копейки или цента (например, '1234' автоматически приведется к '1234.00'). В случае ошибочного значения параметра currency выбрасывается исключение ValueError. Не должно быть значений типа float или других типов, которые не могут быть преобразованы в строку с двумя знаками после запятой для точности до копейки или цента (например, '1234' автоматически приведется к '1234.00'). В случае ошибочного значения параметра currency выбрасывается исключение ValueError. Если значение параметра currency равно None, будет использовано значение по умолчанию 'USD'. В случае ошибочного значения параметра currency выбрасывается исключение ValueError.

**Возвращаемое значение:**

- `str` — Отформатированная строка с денежной суммой и символом валюты (например, '$1234.56').

**Исключения:**

ValueError

**Примеры:**

Форматирование суммы в долларах.

```python
format_price(1234.56)
```

Форматирование суммы в евро.

```python
format_price(1234.56, 'EUR')
```
