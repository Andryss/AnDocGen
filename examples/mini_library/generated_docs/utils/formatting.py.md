## Функции

### `def format_items(*labels: str) -> str`

Соединяет переменное количество меток элементов.

**Параметры:**

- `*labels` (`str`) — —

**Возвращаемое значение:**

- `str` — строка, содержащая соединенные метки

**Примеры:**

Соединить три метки.

```python
format_items('item1', 'item2', 'item3')
```

### `def format_price(amount: float, currency: str = 'USD') -> str`

Форматирует денежное количество с символом валюты.

**Параметры:**

- `amount` (`float`) — денежное количество для форматирования
- `currency` (`str`) — символ валюты (по умолчанию USD)

**Возвращаемое значение:**

- `str` — форматированная строка с символом валюты и двумя знаками после запятой

**Примеры:**

Форматирование цены в долларах.

```python
format_price(123.456)
```

Форматирование цены в евро с указанием символа валюты.

```python
format_price(123.45, 'EUR')
```
