# Модуль `services.py`


Модуль бизнес-логики для работы с заказами.

**Содержание:**

- [Классы](#классы)

## Классы

### `class OrderService`

Класс для координации создания и определения стоимости заказов.

**Назначение:**

Инкапсулирует логику создания и обработки заказов в объектном интерфейсе.

**Использование:**

Создайте экземпляр класса OrderService с нужными параметрами и вызывайте методы для выполнения операций с заказами.

#### Методы

##### `__init__(storage: InMemoryStorage, settings: Settings | None = None) -> None`

Инициализирует объект OrderService с параметрами для управления заказами.

**Параметры:**

- `storage` (`InMemoryStorage`) — хранилище для хранения заказов и товаров.
- `settings` (`Settings | None`) — настройки сервиса; если не указаны, используются настройки по умолчанию.

**Примеры:**

Создать объект OrderService с заданным хранилищем и настройками.

```python
service = OrderService(storage, settings)
```

Создать объект OrderService только с хранилищем.

```python
service = OrderService(storage)
```

##### `add_item(order_id: int, item: Item) -> Order`

Добавляет товар в заказ и возвращает обновленный заказ.

**Параметры:**

- `order_id` (`int`) — ID заказа, к которому добавляется товар. Ожидается положительное целое число, оно же будет использовано для поиска существующего заказа в хранилище.
- `item` (`Item`) — Товар, который нужно добавить в заказ. Ожидается объект класса Item, который содержит информацию о товаре, такую как ID, наименование и количество.

**Возвращаемое значение:**

- `Order` — Обновленный заказ с добавленным товаром.

**Исключения:**

ValidationError: Если указанное количество товара меньше единицы, будет выброшено исключение ValidationError с сообщением 'Quantity must be positive'. Это ограничение валидации применяется для предотвращения ошибок при работе с отрицательными или нулевыми количествами товаров.

##### `create_order(customer: str) -> Order`

Создает новый заказ для указанного клиента.

**Параметры:**

- `customer` (`str`) — имя клиента, для которого создается заказ. Обязательный параметр.

**Возвращаемое значение:**

- `Order` — новый объект заказа

**Исключения:**

ValidationError: если имя клиента не указано или является пустым строкой.

**Примеры:**

Создать заказ для клиента с именем 'Иван'.

```python
order = OrderService.create_order('Иван')
```

##### `summarize(order_id: int) -> dict[str, str | float]`

Суммирует информацию о заказе по идентификатору.

**Параметры:**

- `order_id` (`int`) — идентификатор заказа для суммирования информации о нем.

**Возвращаемое значение:**

- `dict[str, str | float]` — словарь с информацией о заказе: имя клиента, количество товаров и подитоговая стоимость.

**Примеры:**

Получить информацию о заказе по идентификатору.

```python
order_service.summarize(123)
```

##### `quote_total(order_id: int) -> str`

Вычисляет и возвращает общую стоимость заказа включая налог.

**Параметры:**

- `order_id` (`int`) — Идентификатор заказа для которого нужно рассчитать общую сумму.

**Возвращаемое значение:**

- `str` — Общая стоимость заказа в виде строки с символом валюты.

**Примеры:**

Рассчитать общую сумму заказа по идентификатору.

```python
order_service.quote_total(123)
```
