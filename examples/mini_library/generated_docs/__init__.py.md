# Модуль `__init__.py`


Модуль публичного API мини-библиотеки.

**Экспорт:**

- `Item` (`Класс`) — Класс для представления товара.
- `Order` (`Класс`) — Класс для представления заказа.
- `OrderService` (`Класс`) — Сервис для управления заказами.
- `InMemoryStorage` (`Класс`) — Класс для хранения данных в памяти.
- `Settings` (`Класс`) — Класс для настройки параметров мини-библиотеки.
- `MiniLibraryError` (`Исключение`) — Основное исключение для мини-библиотеки.
- `NotFoundError` (`Исключение`) — Исключение при отсутствии запрошенных данных.
- `ValidationError` (`Исключение`) — Исключение при ошибке валидации данных.
- `main` (`Функция`) — Основная функция для командной строки мини-библиотеки.
