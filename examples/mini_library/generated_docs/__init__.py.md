# Модуль `__init__.py`


Мини-библиотека с публичным API для работы с заказами и предметами.

**Экспорт:**

- `Item` (`class`) — Класс, представляющий предмет.
- `Order` (`class`) — Класс, представляющий заказ.
- `OrderService` (`class`) — Сервис для управления заказами.
- `InMemoryStorage` (`class`) — Класс, представляющий хранилище в памяти.
- `Settings` (`class`) — Класс для настройки мини-библиотеки.
- `MiniLibraryError` (`exception`) — Базовое исключение мини-библиотеки.
- `NotFoundError` (`exception`) — Исключение, выбрасываемое при отсутствии ресурса.
- `ValidationError` (`exception`) — Исключение, выбрасываемое при ошибке валидации.
- `main` (`function`) — Главная функция для запуска командной строки мини-библиотеки.
