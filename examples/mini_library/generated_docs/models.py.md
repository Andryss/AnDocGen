# Модуль `models.py`


Модуль models.py для определения данных моделей заказов и элементов.

- [Классы](#классы)

## Классы

### `class Item`

Класс для представления отдельного элемента в заказе.

**Назначение:**

Инкапсулирует свойства и методы для работы с отдельными предметами в заказе.

**Использование:**

Создайте экземпляр класса Item, передав необходимые параметры при его инициализации.

**Поля:**

- `sku` (`str`) — —
- `title` (`str`) — —
- `price` (`float`) — —
- `quantity` (`int`) — —

### `class Order`

Класс для представления заказа в магазине.

**Назначение:**

Инкапсулирует информацию о заказе, включая его стоимость.

**Использование:**

Создайте экземпляр класса Order и используйте метод total() для получения общей стоимости заказа.

**Поля:**

- `order_id` (`int`) — —
- `customer` (`str`) — —
- `items` (`list[Item]`) — —

#### Методы

##### `total() -> float`

Вычисляет общую стоимость заказа.

**Возвращаемое значение:**

- `float` — общая стоимость всех товаров в заказе

**Примеры:**

Вычислить общую стоимость заказа.

```python
order = Order()
# Добавление товаров в заказ
order.items.append(Item(price=10.0, quantity=2))
order.items.append(Item(price=5.0, quantity=3))
total = order.total()
```
