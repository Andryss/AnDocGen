# mini_library


## Корневые модули

| Модуль | Описание |
|--------|--------------|
| [__init__.py](__init__.py.md) | Мини-библиотека с публичным API для работы с заказами и предметами. |
| [cli.py](cli.py.md) | Интерфейс командной строки для мини-библиотеки. |
| [config.py](config.py.md) | Модуль конфигурации с классом для хранения и управления настройками приложения. |
| [exceptions.py](exceptions.py.md) | Модуль исключений для мини-библиотеки с базовыми ошибками. |
| [models.py](models.py.md) | Модуль с классами данных для отдельных элементов в заказах и самих заказов. |
| [services.py](services.py.md) | Модуль бизнес-логики для работы с заказами. |
| [storage.py](storage.py.md) | Модуль для хранения заказов в памяти процесса. |
