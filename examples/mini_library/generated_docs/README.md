# mini_library


## Корневые модули

| Модуль | Описание |
|--------|--------------|
| [__init__.py](__init__.py.md) | Модуль публичного API мини-библиотеки. |
| [cli.py](cli.py.md) | Модуль командной строки для мини-библиотеки. |
| [config.py](config.py.md) | Модуль конфигурации с классом для хранения и управления настройками. |
| [exceptions.py](exceptions.py.md) | Модуль исключений для мини-библиотеки. |
| [models.py](models.py.md) | Модуль models.py для определения данных моделей заказов и элементов. |
| [services.py](services.py.md) | Модуль бизнес-логики для работы с заказами. |
| [storage.py](storage.py.md) | Модуль для хранения заказов в процесс-локальном словаре. |
