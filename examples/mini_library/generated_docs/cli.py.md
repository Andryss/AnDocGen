# Модуль `cli.py`


Модуль командной строки для мини-библиотеки.

**Содержание:**

- [Функции](#функции)

## Функции

### `def build_parser() -> argparse.ArgumentParser`

Создает и возвращает объект ArgumentParser с настройками для командной строки.

**Возвращаемое значение:**

- `argparse.ArgumentParser` — Объект ArgumentParser с настроенными аргументами

**Примеры:**

Создать объект ArgumentParser для командной строки.

```python
parser = build_parser()
```

### `def main(args: list[str] | None = None) -> int`

Запускает демонстрационный поток заказов и выводит зафиксированную сумму.

**Параметры:**

- `args` (`list[str] | None`) — аргументы командной строки для парсера (по умолчанию `None`)

**Возвращаемое значение:**

- `int` — код возврата: всегда 0

**Примеры:**

Запустить демонстрационный поток заказов без аргументов командной строки.

```python
main()
```

Запустить демонстрационный поток заказов с аргументами командной строки.

```python
main(['--customer', 'Alice', '--sku', 'SKU123', '--price', '10.99'])
```
