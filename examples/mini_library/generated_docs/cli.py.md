# Модуль `cli.py`


Интерфейс командной строки для мини-библиотеки.

**Содержание:**

- [Функции](#функции)

## Функции

### `def build_parser() -> argparse.ArgumentParser`

Создает и настраивает объект парсера аргументов для командной строки.

**Возвращаемое значение:**

- `argparse.ArgumentParser` — Объект парсера аргументов для командной строки

**Примеры:**

Создать объект парсера аргументов.

```python
parser = build_parser()
```

### `def main(args: list[str] | None = None) -> int`

Запускает демонстрационный поток заказов и выводит зафиксированную сумму.

**Параметры:**

- `args` (`list[str] | None`) — Список аргументов командной строки

**Возвращаемое значение:**

- `int` — Статус завершения программы

**Побочные эффекты:**

Ничего не меняет, только выводит информацию в консоль.

**Примеры:**

Запустить демонстрационный поток заказов с аргументами командной строки.

```python
main(['--customer', 'John Doe', '--sku', 'SKU123', '--price', '100.50'])
```
