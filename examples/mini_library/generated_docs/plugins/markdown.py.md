# Модуль `plugins/markdown.py`


Модуль экспорта SUMM заказов в формат Markdown.

**Содержание:**

- [Классы](#классы)

## Классы

### `class MarkdownExporter(PluginBase)`

Класс для экспорта сумм заказов в формат Markdown.

**Назначение:**

Инкапсулирует процесс экспорта данных заказов в текстовый формат Markdown.

**Использование:**

Создайте экземпляр класса и вызовите метод export с данными заказов для получения строки с отформатированным содержимым.

**Наследование:**

- `PluginBase`

#### Методы

##### `__init__(*args: Any, **kwargs: Any) -> None`

Инициализирует экземпляр MarkdownExporter.

**Параметры:**

- `*args` (`Any`) — Необязательные позиционные аргументы, переданные родительскому классу.
- `**kwargs` (`Any`) — Необязательные именованные аргументы, переданные родительскому классу.

**Примеры:**

Создать экземпляр MarkdownExporter с заданным заголовком.

```python
exporter = MarkdownExporter(heading='Этот текст')
```

##### `export(data: dict[str, Any]) -> str`

Экспортирует данные в формат Markdown.

**Параметры:**

- `data` (`dict[str, Any]`) — словарь данных для экспорта в формат Markdown. Ключи и значения словаря должны быть строками и любыми типами данных соответственно.

**Возвращаемое значение:**

- `str` — строка, содержащая данные в формате Markdown

**Примеры:**

Экспортировать данные.

```python
export({'name': 'John', 'age': 30})
```
