# Модуль `plugins/base.py`


Модуль с базовым классом для экспортирующих плагинов.

**Содержание:**

- [Классы](#классы)

## Классы

### `class PluginBase(ABC)`

Базовый класс для экспортирующих плагинов.

**Назначение:**

Предоставляет основные методы и структуру для создания плагинов экспортных данных.

**Использование:**

Создайте подкласс от PluginBase и реализуйте абстрактный метод export для определения логики экспорта.

**Наследование:**

- `ABC`

#### Методы

##### `__init__(*args: Any, **kwargs: Any) -> None`

Инициализирует экземпляр класса PluginBase с опциями.

**Параметры:**

- `*args` (`Any`) — неименованные аргументы, игнорируются в данном методе
- `**kwargs` (`Any`) — именованные аргументы, которые сохраняются как словарь в атрибут self.options

**Возвращаемое значение:**

- `None` — Нет значений, возвращаемых этим методом

**Примеры:**

Создать экземпляр PluginBase с опциями.

```python
plugin = PluginBase(option1='value1', option2='value2')
```

##### `export(data: dict[str, Any]) -> str`

Сериализует данные в строковое представление.

**Параметры:**

- `data` (`dict[str, Any]`) — словарь данных для сериализации.

**Возвращаемое значение:**

- `str` — строка, представляющая собой сериализованные данные.

**Примеры:**

Сериализовать словарь данных.

```python
PluginBase.export({'key': 'value'})
```
