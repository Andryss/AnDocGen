# Документация AnDocGen: второй отчёт

Каталог `docs/second_report/` содержит материалы второго отчёта по теме «Реализация метода оценки качества сгенерированной технической документации из исходного кода».

Документы соответствуют этапам [индивидуального задания](individual_assignment.md) и оформляются в Markdown для последующей конвертации в DOCX через Pandoc.

## Соответствие этапам задания

| Этап | Документ | Содержание |
|------|----------|------------|
| 3 | [literature_review.md](literature_review.md) | Обзор научных работ, классификация методов оценки качества документации, сравнительный анализ их возможностей и ограничений |
| 4 | [evaluation_method.md](evaluation_method.md) | Характеристики качества, показатели и правила их интерпретации, алгоритм расчёта итоговой оценки, блок-схема, форматы входных и выходных данных |
| 5 | [implementation.md](implementation.md) | Структура модуля оценки, интеграция с прототипом, классы и методы, функциональная проверка, примеры результатов |
| 6 | [project_selection.md](project_selection.md) | Критерии отбора и состав экспериментальной выборки, версии проектов, характеристики исходного кода и документации |
| 7 | [evaluation.md](evaluation.md) | Результаты апробации, сводная статистика, сравнительные графики, ограничения и выводы |

Организационные этапы 1–2, оформление отчётных документов на этапе 8 и получение отзыва на этапе 9 описаны в индивидуальном задании.

## Рекомендуемый порядок чтения

1. [individual_assignment.md](individual_assignment.md) — тема, этапы, длительность и ожидаемые результаты.
2. [literature_review.md](literature_review.md)
3. [evaluation_method.md](evaluation_method.md)
4. [implementation.md](implementation.md)
5. [project_selection.md](project_selection.md)
6. [evaluation.md](evaluation.md)
7. [README проекта](../../README.md) — установка и быстрый старт.

## Конвертация в DOCX

Команда выполняется из корня репозитория:

```bash
pandoc docs/second_report/individual_assignment.md -o individual_assignment.docx
```

Остальные документы конвертируются аналогично. Требования к оформлению итогового отчёта приведены в этапе 8 индивидуального задания.
