# Исторические отчёты AnDocGen

Каталог `docs/` содержит материалы трёх исторических отчётов. Каждый отчёт
фиксирует состояние проекта и результаты работы на определённую дату.
Дата фиксации указывается при завершении подготовки отчёта. После фиксации
материалы отчёта не изменяются и не обновляются вслед за развитием проекта.
Результаты последующих работ оформляются в новых отчётах.

Актуальная информация об установке и использовании системы находится в
[README проекта](../README.md), правила работы ИИ-агентов — в
[AGENTS.md](../AGENTS.md).

- **Дата отчёта:** 21.01.2026.

Отчёт содержит список источников и аналитический обзор применения

документации: классификацию подходов, сравнительный и критический анализ,
обоснование актуальности и перспективные направления исследований.

- [Состав отчёта](preliminary_report/README.md)
- [Индивидуальное задание и план-график](preliminary_report/individual_assignment.md)
