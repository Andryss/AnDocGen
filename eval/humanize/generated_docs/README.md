# humanize

Документация проекта, сгенерированная AnDocGen.

## Корневые модули

| Модуль | Описание |
|--------|--------------|
| [__init__.py](__init__.py.md) | Основной модуль пакета для форматирования чисел и дат в более читаемый вид. |
| [filesize.py](filesize.py.md) | Модуль для форматирования числа байтов в человеко-читаемый размер файла. |
| [i18n.py](i18n.py.md) | Модуль `i18n.py` содержит функции для активации и деактивации интернационализации, а также возврата разделителей десятичной точки и тысяч. |
| [lists.py](lists.py.md) | Модуль для человеческого форматирования списков. |
| [number.py](number.py.md) | Модуль для работы с числами, включая преобразование в порядковые числа, добавление запятых, форматирование дробей и пр. |
| [time.py](time.py.md) | Модуль для создания "человеческого" представления времени и даты. |
