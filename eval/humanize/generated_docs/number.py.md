# Модуль `number.py`

## Функции

### `def _format_not_finite(value: float) -> str`

Функция для обработки случаев бесконечности и NaN.

**Параметры:**

- `value` (`float`) — значение для проверки

**Возвращаемое значение:**

- `str` — строковое представление значения или пустая строка, если значение не является бесконечностью или NaN

**Примеры:**

```python
print(_format_not_finite(float('nan')))  # Output: "NaN"
print(_format_not_finite(float('-inf'))) # Output: "-Inf"
print(_format_not_finite(float('inf')))  # Output: "+Inf"
print(_format_not_finite(0))          # Output: ""
```

### `def clamp(value: float, format: str = '{:}', floor: float | None = None, ceil: float | None = None, floor_token: str = '<', ceil_token: str = '>') -> str`

Функция `clamp` возвращает отформатированное число, ограниченное указанными пределами. Если число превышает верхний предел или ниже нижнего, оно будет заменено на соответствующий предел, сформатированное и префиксом, указывающим на это.

**Параметры:**

- `value` (`float`) — Входное число.
- `format` (`str OR callable`) — Могут быть либо строкой формата, либо функцией, принимающей значение и возвращающей строку.
- `floor` (`float | None`) — Наименьшее допустимое значение перед ограничением.
- `ceil` (`float | None`) — Наибольшее допустимое значение перед ограничением.
- `floor_token` (`str`) — Если значение меньше нижнего предела, токен будет добавлен в начало вывода.
- `ceil_token` (`str`) — Если значение превышает верхний предел, токен будет добавлен в начало вывода.

**Возвращаемое значение:**

- `str` — Отформатированное число. Вывод ограничен указанными пределами. Если значение больше верхнего или меньше нижнего предела, оно будет префиксом, указывающим на это.

**Примеры:**

```pycon
>>> clamp(123.456)
'123.456'
>>> clamp(0.0001, floor=0.01)
'<0.01'
>>> clamp(0.99, format="{:.0%}", ceil=0.99)
'99%'
>>> clamp(0.999, format="{:.0%}", ceil=0.99)
'>99%'
>>> clamp(1, format=intword, floor=1e6, floor_token="under ")
'under 1.0 million'
>>> clamp(None) is None
True
```

### `def apnumber(value: NumberOrString) -> str`

Функция преобразует целое число в формат Associated Press. Для чисел от 0 до 9 возвращает их словесное представление, для других чисел и строковых значений — саму строку.

**Параметры:**

- `value` (`NumberOrString`) — Целое число или строка, которое нужно преобразовать.

**Возвращаемое значение:**

- `str` — Словесное представление числа для чисел от 0 до 9, иначе исходная строка или число в виде строки.

**Примеры:**

```pycon
>>> apnumber(0)
'zero'
>>> apnumber(5)
'five'
>>> apnumber(10)
'10'
>>> apnumber("7")
'seven'
>>> apnumber("foo")
'foo'
>>> apnumber(None)
'None'
```

### `def fractional(value: NumberOrString) -> str`

Преобразует число в строковое представление дроби.

**Параметры:**

- `value` (`NumberOrString`) — Число или строка, которое нужно преобразовать.

**Возвращаемое значение:**

- `str` — Строковое представление дроби.

**Примеры:**

```pycon
>>> fractional(0.3)
'3/10'
>>> fractional(1.3)
'1 3/10'
>>> fractional(float(1/3))
'1/3'
>>> fractional(1)
'1'
>>> fractional("ten")
'ten'
>>> fractional(None)
'None'
```

### `def intcomma(value: NumberOrString, ndigits: int | None = None) -> str`

Преобразует целое число в строку с запятыми каждые три разряда.

**Параметры:**

- `value` (`NumberOrString`) — Целое число или строка для преобразования.
- `ndigits` (`int | None`) — Количество цифр после десятичной точки для округления. Если значение равно `None`, не выполняется округление.

**Возвращаемое значение:**

- `str` — Строка с запятыми каждые три разряда.

**Примеры:**

```pycon
>>> intcomma(100)
'100'
>>> intcomma("1000")
'1,000'
>>> intcomma(1_000_000)
'1,000,000'
>>> intcomma(1_234_567.25)
'1,234,567.25'
>>> intcomma(1234.5454545, 2)
'1,234.55'
>>> intcomma(14308.40, 1)
'14,308.4'
>>> intcomma("14308.40", 1)
'14,308.4'
>>> intcomma(None)
'None'
```

### `def ordinal(value: NumberOrString, gender: str = 'male') -> str`

Преобразует целое число в его порядковый числительный в виде строки.

**Параметры:**

- `value` (`NumberOrString`) — Целое число или строка, которую можно преобразовать в целое число.
- `gender` (`str`) — Пол для перевода. Принимает либо "male", либо "female".

**Возвращаемое значение:**

- `str` — Порядковый числительный в виде строки.

**Примеры:**

```pycon
>>> ordinal(1)
'1st'
>>> ordinal(1002)
'1002nd'
>>> ordinal(103)
'103rd'
>>> ordinal(4)
'4th'
>>> ordinal(12)
'12th'
>>> ordinal(101)
'101st'
>>> ordinal(111)
'111th'
>>> ordinal("something else")
'something else'
>>> ordinal([1, 2, 3]) == "[1, 2, 3]"
True
```

### `def scientific(value: NumberOrString, precision: int = 2) -> str`

Возвращает число в виде строки в научной записи z.wq x 10ⁿ.

**Параметры:**

- `value` (`int, float, str`) — Вводное число.
- `precision` (`int`) — Количество десятичных знаков для первой части числа.

**Возвращаемое значение:**

- `str` — Число в научной записи z.wq x 10ⁿ.

**Примеры:**

```pycon
>>> scientific(float(0.3))
'3.00 x 10⁻¹'
>>> scientific(int(500))
'5.00 x 10²'
>>> scientific(-1000)
'-1.00 x 10³'
>>> scientific(1000, 1)
'1.0 x 10³'
>>> scientific(1000, 3)
'1.000 x 10³'
>>> scientific("99")
'9.90 x 10¹'
>>> scientific("foo")
'foo'
>>> scientific(None)
'None'
```

### `def metric(value: float, unit: str = '', precision: int = 3) -> str`

Возвращает значение с префиксом из метрических единиц SI.

**Параметры:**

- `value` (`float`) — входное число.
- `unit` (`str, optional`) — опциональная базовая единица.
- `precision` (`int, optional`) — количество цифр в выводе, которое должно содержаться.

**Возвращаемое значение:**

- `str` — значение с префиксом из метрических единиц SI

**Примеры:**

```pycon
>>> metric(1500, "V")
'1.50 kV'
>>> metric(2e8, "W")
'200 MW'
>>> metric(220e-6, "F")
'220 μF'
>>> metric(1e-14, precision=4)
'10.00 f'

>>> metric(1e40)
'1.00 x 10⁴⁰'
```
