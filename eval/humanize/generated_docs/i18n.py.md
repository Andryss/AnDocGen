## Функции

### `def _get_default_locale_path() -> pathlib.Path | None`

Возвращает путь к директории по умолчанию для локализации.

**Возвращаемое значение:**

- `pathlib.Path | None` — путь к директории по умолчанию для локализации или `None`, если не удалось определить пакет

**Примеры:**

```python
result = _get_default_locale_path()
print(result)  # выводит путь к директории по умолчанию для локализации или None, если не удалось определить пакет
```

### `def _gettext_noop(message: str) -> str`

Маркирует строку как строку для перевода без ее фактического перевода.

**Параметры:**

- `message` (`str`) — Текст, который будет переведен в будущем.

**Возвращаемое значение:**

- `str` — Исходный текст, не изменяется.

**Примеры:**

```python
CONSTANTS = [_gettext_noop('first'), _gettext_noop('second')]
def num_name(n):
    return _gettext(CONSTANTS[n])
```

### `def _ngettext_noop(singular: str, plural: str) -> tuple[str, str]`

Отмечает две строки как переводы во множественном числе без их перевода.

**Параметры:**

- `singular` (`str`) — строка в единственном числе для будущего перевода.
- `plural` (`str`) — строка во множественном числе для будущего перевода.

**Возвращаемое значение:**

- `tuple[str, str]` — оригинальные строки без изменений.

**Примеры:**

```python
CONSTANTS = [ngettext_noop('first', 'firsts'), ngettext_noop('second', 'seconds')]
def num_name(n):
    return _ngettext(*CONSTANTS[n])
```

### `def deactivate() -> None`

Отключает международизацию.

**Побочные эффекты:**

Изменяет значение атрибута `_CURRENT.locale` на `None`.

**Примеры:**

```python
deactivate()
```

### `def decimal_separator() -> str`

Возвращает разделитель десятичной точки для текущего локали, по умолчанию используется точка.

**Возвращаемое значение:**

- `str` — Разделитель десятичной точки.

**Примеры:**

```python
decimal_separator()  # Вернет разделитель десятичной точки для текущей локали, например ".", ",", или другой символ.
```

### `def get_translation() -> gettext_module.NullTranslations`

Возвращает объект для локализации на основе текущего языка.

**Возвращаемое значение:**

- `gettext_module.NullTranslations` — объект для локализации или объект по умолчанию, если язык не определен

**Примеры:**

```python
translation = get_translation()
```

### `def thousands_separator() -> str`

Возвращает разделитель тысяч для локали, по умолчанию запятая.

**Возвращаемое значение:**

- `str` — разделитель тысяч

### `def _gettext(message: str) -> str`

Возвращает переведённый текст.

**Параметры:**

- `message` (`str`) — текст, который нужно перевести

**Возвращаемое значение:**

- `str` — переведённый текст

**Примеры:**

```python
translated_text = _gettext("Привет, мир!")
print(translated_text)  # Вывод: Hello, world!
```

**Смотрите также:**

- `get_translation` — Возвращает объект для локализации на основе текущего языка.

### `def activate(locale: str | None, path: str | os.PathLike[str] | None = None) -> gettext_module.NullTranslations`

Активирует интернационализацию.

Устанавливает текущую локаль и ищет локализационные файлы в указанном каталоге.

**Параметры:**

- `locale` (`str | None`) — Имя языка, например, `en_GB`. Если `None`, по умолчанию не используется перевод. Аналогично вызову `deactivate()`.
- `path` (`str | os.PathLike[str] | None`) — Путь к каталогу для поиска локализационных файлов.

**Возвращаемое значение:**

- `gettext_module.NullTranslations` — Переводы.

**Исключения:**

- `FileNotFoundError`: Если невозможно найти папку с локальными файлами.

**Примеры:**

```python
translations = activate("en_GB", "/path/to/locales")
```

**Смотрите также:**

- `_get_default_locale_path`

### `def _ngettext(message: str, plural: str, num: int) -> str`

Функция для получения перевода текста в зависимости от числа.

**Параметры:**

- `message` (`str`) — текст в единственном числе, который нужно перевести.
- `plural` (`str`) — текст во множественном числе, который нужно перевести.
- `num` (`int`) — количество элементов для определения правильной формы переводимого слова.

**Возвращаемое значение:**

- `str` — переведенный текст в зависимости от числа.

**Примеры:**

```python
translated_text = _ngettext("apple", "apples", 1)  # apple
translated_text = _ngettext("apple", "apples", 2)  # apples
```

**Смотрите также:**

- `def get_translation() -> gettext_module.NullTranslations` — Возвращает объект для локализации на основе текущего языка.

### `def _pgettext(msgctxt: str, message: str) -> str`

Извлекает конкретный перевод.

Работает с модификаторами `msgctxt` в файлах `.po` и позволяет использовать одинаковые ключи с разными переводами.

**Параметры:**

- `msgctxt` (`str`) — Контекст перевода.
- `message` (`str`) — Текст для перевода.

**Возвращаемое значение:**

- `str` — Переведенный текст.

**Примеры:**

```python
# Пример использования _pgettext
translated_text = _pgettext("app", "Save")
print(translated_text)
```

**Смотрите также:**

- `def get_translation() -> gettext_module.NullTranslations` — Возвращает объект для локализации на основе текущего языка.
