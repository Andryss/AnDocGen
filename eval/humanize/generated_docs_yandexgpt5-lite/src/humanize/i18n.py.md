# Модуль `src/humanize/i18n.py`


Модуль для активации, получения и деактивации переводов.

**Экспорт:**

- `activate` (`function(locale: str | None, path: str | os.PathLike[str] | None = None) -> gettext_module.NullTranslations`) — Активирует интернационализацию, устанавливая текущий язык и ища локализации в указанном каталоге
- `deactivate` (`function() -> None`) — Отключить интернационализацию
- `decimal_separator` (`function() -> str`) — Возвращает десятичный разделитель для локали, по умолчанию точку
- `thousands_separator` (`function() -> str`) — Возвращает разделитель тысяч для локали, по умолчанию — запятая

**Содержание:**

- [Функции](#функции)

## Функции

### `def _get_default_locale_path() -> pathlib.Path | None`

Возвращает путь к папке locale по умолчанию или None, если не удалось определить

**Возвращаемое значение:**

- `pathlib.Path | None` — Путь к папке locale по умолчанию или None, если не удалось определить

**Примеры:**

Получить путь к папке locale по умолчанию

```python
from humanize.i18n import _get_default_locale_path
path = _get_default_locale_path()
```

### `def _gettext_noop(message: str) -> str`

Отметить строку как строку для перевода без перевода

**Параметры:**

- `message` (`str`) — Текст для перевода в будущем

**Возвращаемое значение:**

- `str` — Оригинальный текст, без изменений

**Примеры:**

Отметить строку как строку для перевода без перевода

```python
_gettext_noop('first')
```

### `def _ngettext_noop(singular: str, plural: str) -> tuple[str, str]`

Отметить две строки как множественные переводы без их перевода.

**Параметры:**

- `singular` (`str`) — Отметить две строки как множественные переводы без их перевода.
- `plural` (`str`) — Множественный текст для перевода в будущем.

**Возвращаемое значение:**

- `tuple[str, str]` — Возвращает исходные тексты без изменений

**Примеры:**

Пример использования функции _ngettext_noop для создания констант с переведёнными строками

```python
CONSTANTS = [ngettext_noop('first', 'firsts'), ngettext_noop('second', 'seconds')]
def num_name(n):
    return _ngettext(*CONSTANTS[n])
```

### `def activate(locale: str | None, path: str | os.PathLike[str] | None = None) -> gettext_module.NullTranslations`

Активирует интернационализацию, устанавливая текущий язык и ища локализации в указанном каталоге.

**Параметры:**

- `locale` (`str | None`) — Устанавливает текущий язык. Если None, то перевод не применяется. Аналогично вызову deactivate().
- `path` (`str | os.PathLike[str] | None`) — Путь для поиска локализаций.

**Возвращаемое значение:**

- `gettext_module.NullTranslations` — Translations

**Исключения:**

FileNotFoundError: If humanize cannot find the locale folder

**Примеры:**

Активировать локализацию 'en_GB' в указанном каталоге

```python
activate('en_GB', '/path/to/locale')
```

**Смотрите также:**

def _get_default_locale_path() -> pathlib.Path | None

### `def _ngettext(message: str, plural: str, num: int) -> str`

Возвращает перевод с учётом числа, используя множественное число, если это необходимо.

**Параметры:**

- `message` (`str`) — Одиночный текст для перевода
- `plural` (`str`) — Множественный текст для перевода
- `num` (`int`) — Число, определяющее перевод для соответствующего грамматического числа

**Возвращаемое значение:**

- `str` — Переведённый текст

**Примеры:**

Перевод единственного сообщения.

```python
return _ngettext('Сообщение', 'Сообщения', 1)
```

Перевод множественного числа сообщений.

```python
return _ngettext('Сообщение', 'Сообщения', 2)
```

### `def _pgettext(msgctxt: str, message: str) -> str`

Извлекает конкретный перевод.

**Параметры:**

- `msgctxt` (`str`) — Контекст перевода
- `message` (`str`) — Текст для перевода

**Возвращаемое значение:**

- `str` — Переведённый текст

**Примеры:**

Получить перевод с учётом контекста

```python
_pgettext('context', 'message')
```

**Смотрите также:**

def get_translation() -> gettext_module.NullTranslations — Возвращает перевод с использованием текущей локали.
