# Модуль `src/humanize/filesize.py`


Модуль humanize/filesize.py для работы с размерами файлов в удобочитаемом формате.

**Содержание:**

- [Функции](#функции)

## Функции

### `def naturalsize(value: float | str, binary: bool = False, gnu: bool = False, format: str = '%.1f') -> str`

Форматирует число байт в удобочитаемый формат размера файла (например, 10 kB).

**Параметры:**

- `binary` (`bool`) — Если True, используются двоичные суффиксы (KiB, MiB) с основанием 2^10 вместо 10^3.
- `gnu` (`bool`) — Если True, используются префиксы в стиле GNU (K, M) с определением 2^10.
- `format` (`str`) — Пользовательский форматтер.
- `value` (`int, float, str`) — Целое число для преобразования.

**Возвращаемое значение:**

- `str` — Человекочитаемое представление размера файла.

**Примеры:**

Преобразовать 3000000 байт в удобочитаемый формат

```python
naturalsize(3000000)
```

Преобразовать 300 байт с использованием двоичных суффиксов

```python
naturalsize(300, False, True)
```

Преобразовать 3000 байт с использованием двоичных суффиксов

```python
naturalsize(3000, False, True)
```

Преобразовать 3000 байт с использованием двоичных суффиксов и формата с тремя знаками после запятой

```python
naturalsize(3000, False, True, "%.3f")
```

Преобразовать 3000 байт с использованием двоичных суффиксов

```python
naturalsize(3000, True)
```

Преобразовать 10^28 байт в удобочитаемый формат

```python
naturalsize(10**28)
```

Преобразовать 3 * 10^34 байт в удобочитаемый формат

```python
naturalsize(10**34 * 3)
```

Преобразовать -4096 байт с использованием двоичных суффиксов

```python
naturalsize(-4096, True)
```
