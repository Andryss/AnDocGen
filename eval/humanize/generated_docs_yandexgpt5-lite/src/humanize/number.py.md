**Параметры:**

### `def clamp(value: float, format: str = '{:}', floor: float | None = None, ceil: float | None = None, floor_token: str = '<', ceil_token: str = '>') -> str`

Возвращает число с указанным форматом, ограниченное floor и ceil. Если число больше ceil или меньше floor, возвращается соответствующий предел, отформатированный и с добавленным токеном.

**Параметры:**

- `value` (`float`) — Входное число.
- `format` (`str | callable`) — Может быть строкой формата или вызываемой функцией, которая получает value и возвращает строку.
- `floor` (`float | None`) — Наименьшее значение перед ограничением.
- `ceil` (`float | None`) — Наибольшее значение перед ограничением.
- `floor_token` (`str`) — Если значение меньше floor, токен будет добавлен к выводу.
- `ceil_token` (`str`) — Если значение больше ceil, токен будет добавлен к выводу.

**Возвращаемое значение:**

- `str` — Строка с отформатированным числом, ограниченным floor и ceil.

**Исключения:**

ValueError

**Примеры:**

Возвращает число без изменений.

```python
clamp(123.456)
```

Возвращает floor с токеном, если значение меньше floor.

```python
clamp(0.0001, floor=0.01)
```

Возвращает значение, равное ceil, с токеном, если значение больше ceil.

```python
clamp(0.99, format="{:.0%}", ceil=0.99)
```

Возвращает значение, равное ceil, с токеном, если значение больше ceil.

```python
clamp(0.999, format="{:.0%}", ceil=0.99)
```

Возвращает floor с токеном, если значение меньше floor, используя формат intword.

```python
clamp(1, format=intword, floor=1e6, floor_token="under ")
```

Возвращает None, если переданное значение равно None.

```python
clamp(None) is None
```

### `def intcomma(value: NumberOrString, ndigits: int | None = None) -> str`

Преобразует целое число или число с плавающей точкой в строку с запятыми каждые три цифры.

**Параметры:**

- `ndigits` (`int | None`) — Количество знаков после запятой для округления числа с плавающей точкой.
- `value` (`NumberOrString`) — Целое число или число с плавающей точкой для преобразования в строку с запятыми каждые три цифры.

**Возвращаемое значение:**

- `str` — Строка, содержащая запятые каждые три цифры.

**Примеры:**

Преобразование целого числа в строку с запятыми каждые три цифры.

```python
intcomma(100)
```

Преобразование строки в строку с запятыми каждые три цифры.

```python
intcomma("1000")
```

Преобразование большого целого числа в строку с запятыми каждые три цифры.


Преобразование числа с плавающей точкой с указанием количества знаков после запятой.

Преобразование числа с плавающей точкой с указанием количества знаков после запятой.

Преобразование None в строку.

```python

```

### `def metric(value: float, unit: str = '', precision: int = 3) -> str`

Возвращает значение с префиксом метрической системы СИ, приложенным к числу.

**Параметры:**

- `value` (`float, int`) — Входное число (int, float).
- `unit` (`str`) — Базовая единица измерения (str).
- `precision` (`int`) — Количество цифр, которое должно содержаться в выводе (int).

**Возвращаемое значение:**

- `str` — Строковое представление числа с приложенным префиксом метрической системы СИ.

**Примеры:**

Вернуть значение с префиксом метрической системы СИ, приложенным к числу.

```python
metric(1500, "V")
```

Вернуть значение с префиксом метрической системы СИ, приложенным к числу.

```python
metric(2e8, "W")
```

Вернуть значение с префиксом метрической системы СИ, приложенным к числу.

```python
metric(220e-6, "F")
```

Вернуть значение с префиксом метрической системы СИ, приложенным к числу, с заданной точностью.

```python
metric(1e-14, precision=4)
```

Вернуть значение в научной нотации, так как число слишком велико для представления без ведущих нулей.


### `def intword(value: NumberOrString, format: str = '%.1f') -> str`

Преобразует большое целое число в удобное текстовое представление.

**Параметры:**

- `format` (`str`) — Формат для изменения количества десятичных знаков или общего формата числовой части.
- `value` (`NumberOrString`) — Целое число для преобразования.

**Возвращаемое значение:**

- `str` — Удобное текстовое представление в виде строки, если переданное значение не удалось преобразовать в int.

**Примеры:**

Преобразовать число 100.

```python
intword("100")
```

Преобразовать число 12400.

```python
intword("12400")
```

Преобразовать число 1000000.

```python
intword("1000000")
```

Преобразовать число 1.2 миллиарда.

```python
intword(1_200_000_000)
```

Преобразовать число 8.1 дециллион.

```python
intword(8100000000000000000000000000000000)
```

Преобразовать None.

```python
intword(None)
```

Преобразовать число 1.234 миллиона.

```python
intword("1234000", "%0.3f")
```
