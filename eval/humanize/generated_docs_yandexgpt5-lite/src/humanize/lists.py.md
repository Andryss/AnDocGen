## Функции

### `def natural_list(items: list[Any]) -> str`

Преобразует список элементов в строку, удобную для чтения человеком, с запятыми и 'and' в нужных местах.

**Параметры:**

- `items` (`list[Any]`) — Преобразовать список элементов в строку, удобную для чтения человеком, с запятыми и 'and' в нужных местах.

**Возвращаемое значение:**

- `str` — Строка с запятыми и 'and' в нужных местах.

**Примеры:**

Преобразовать список из трёх элементов.

```python
natural_list(['one', 'two', 'three'])
```

Преобразовать список из двух элементов.

```python
natural_list(['one', 'two'])
```

Преобразовать список из одного элемента.

```python
natural_list(['one'])
```
