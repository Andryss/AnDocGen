## Модули

| Модуль | Описание |
|--------|--------------|
| [__init__.py](__init__.py.md) | Модуль humanize содержит различные утилиты для преобразования чисел и дат в удобочитаемый формат. |
| [filesize.py](filesize.py.md) | Модуль humanize/filesize.py для работы с размерами файлов в удобочитаемом формате. |

| [number.py](number.py.md) | Модуль humanize/number.py содержит функции для преобразования чисел в удобочитаемый формат. |
| [time.py](time.py.md) | Модуль содержит функции для преобразования дат, времени и временных интервалов в естественный, удобный для чтения человеком формат. |
