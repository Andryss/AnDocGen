# Модуль `src/humanize/__init__.py`


Модуль humanize содержит различные утилиты для преобразования чисел и дат в удобочитаемый формат.

**Экспорт:**

- `__version__` (`string`) — Версия модуля
- `activate` (`function`) — Активирует локализацию
- `apnumber` (`function`) — Возвращает число в формате AP Number
- `clamp` (`function`) — Ограничивает значение в диапазоне
- `deactivate` (`function`) — Деактивирует локализацию
- `decimal_separator` (`string`) — Разделитель десятичной части числа
- `fractional` (`function`) — Возвращает дробную часть числа
- `intcomma` (`function`) — Возвращает число с разделителем в виде запятой
- `intword` (`function`) — Возвращает число в виде слов
- `metric` (`function`) — Возвращает число в метрическом формате
- `natural_list` (`function`) — Возвращает список в естественном формате
- `naturaldate` (`function`) — Возвращает дату в естественном формате
- `naturalday` (`function`) — Возвращает день в естественном формате
- `naturaldelta` (`function`) — Возвращает дельту в естественном формате
- `naturalsize` (`function`) — Возвращает размер в естественном формате
- `naturaltime` (`function`) — Возвращает время в естественном формате
- `ordinal` (`function`) — Возвращает порядковый номер
- `precisedelta` (`function`) — Возвращает точную дельту
- `scientific` (`function`) — Возвращает число в научном формате
- `thousands_separator` (`string`) — Разделитель тысяч в числе
