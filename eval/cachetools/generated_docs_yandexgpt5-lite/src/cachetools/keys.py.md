# Модуль `src/cachetools/keys.py`


Модуль предоставляет функции для создания ключей кэша, используемых с декораторами мемоизации.

**Экспорт:**

- `hashkey` (`function`) — Возвращает ключ кэша для заданных хэшируемых аргументов.
- `methodkey` (`function`) — Возвращает ключ кэша для использования с кэшируемыми методами.
- `typedkey` (`function`) — Возвращает типизированный ключ кэша для заданных хеш-аргументов.
- `typedmethodkey` (`function`) — Возвращает типизированный ключ кэша для использования с кэшируемыми методами.

**Содержание:**

- [Классы](#классы)

## Классы

### `class _HashedTuple(tuple)`

Класс _HashedTuple является наследником tuple и гарантирует, что метод hash() будет вызван не более одного раза для каждого элемента.

**Назначение:**

Класс _HashedTuple обеспечивает, чтобы метод hash() вызывался не более одного раза для каждого элемента, поскольку декораторы кэша могут многократно хэшировать ключ при промахе кэша.

**Наследование:**

- `tuple`

##### `__add__(other, add = tuple.__add__)`

Возвращает новый объект _HashedTuple, полученный в результате сложения двух объектов.

**Параметры:**

- `other` (`object`) — Второй объект для сложения
- `add` (`function`) — Метод для сложения

**Возвращаемое значение:**

- `object` — Новый объект _HashedTuple, полученный в результате сложения

**Примеры:**

Сложение двух объектов типа _HashedTuple

```python

```

##### `__radd__(other, add = tuple.__add__)`

Возвращает новый объект _HashedTuple, созданный из результата сложения other и self с помощью метода add

**Параметры:**

- `add` (`function`) — метод, используемый для сложения other и self
- `other` (`object`) — объект, с которым происходит сложение

**Возвращаемое значение:**

- `_HashedTuple` — новый объект _HashedTuple, созданный из результата сложения other и self

**Примеры:**

Вызывается метод __radd__ для объекта _HashedTuple, который возвращает новый объект _HashedTuple, созданный из результата сложения other и self с помощью метода add

```python
return _HashedTuple(add(other, self))
```

##### `__hash__(hash = tuple.__hash__)`

Возвращает хэш объекта _HashedTuple.

**Параметры:**

- `hash` (`function or NoneType`) — N/A

**Возвращаемое значение:**

- `int` — Целочисленное значение хэша

**Примеры:**

Пример использования кэширования для вычисления чисел Фибоначчи

```python
from cachetools import cached, LRUCache, TTLCache
@cached(cache={})
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

Пример использования кэширования для получения Python Enhancement Proposals

```python
from cachetools import cached, LRUCache
@cached(cache=LRUCache(maxsize=32))
def get_pep(num):
    url = 'http://www.python.org/dev/peps/pep-%04d/' % num
    with urllib.request.urlopen(url) as s:
        return s.read()
```

Пример использования кэширования для получения данных о погоде

```python
from cachetools import cached, TTLCache
@cached(cache=TTLCache(maxsize=1024, ttl=600))
def get_weather(place):
    return owm.weather_at_place(place).get_weather()
```
