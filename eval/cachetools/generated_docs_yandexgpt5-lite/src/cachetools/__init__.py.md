# Модуль `src/cachetools/__init__.py`


Модуль cachetools предоставляет различные мемоизирующие коллекции и декораторы, включая варианты декоратора функции @lru_cache из стандартной библиотеки Python.

**Экспорт:**

- `Cache` (`class`) — Класс Cache предназначен для работы с кэшем фиксированного максимального размера, выбирая алгоритм вытеснения элементов при достижении этого размера.
- `FIFOCache` (`class`) — Класс FIFOCache представляет собой реализацию кэша по принципу FIFO, который управляет элементами на основе порядка их добавления.
- `LFUCache` (`class`) — Класс LFUCache представляет собой реализацию кэша по принципу Least Frequently Used (LFU), который выбирает элементы для удаления на основе частоты их использования.
- `LRUCache` (`class`) — Класс LRUCache представляет собой реализацию кэша, в котором элементы удаляются в соответствии с принципом LRU (наименее использованный).
- `RRCache` (`class`) — Класс RRCache представляет собой реализацию кэша с алгоритмом случайного замещения (RR).
- `TLRUCache` (`class`) — Класс TLRUCache представляет собой реализацию кэша с учётом времени использования (TLRU), который управляет элементами на основе их последнего использования и времени их актуальности.
- `TTLCache` (`class`) — Класс TTLCache представляет собой реализацию LRU Cache с указанием времени жизни (TTL) для каждого элемента.
- `cached` (`def`) — Декоратор для обёртывания функции с мемоизацией, сохраняющей результаты в кэше.
- `cachedmethod` (`def`) — Декоратор для обёртывания метода с мемоизацией, сохраняющей результаты в кэше.

### `class Cache(collections.abc.MutableMapping)`

Класс Cache предназначен для работы с кэшем фиксированного максимального размера, выбирая алгоритм вытеснения элементов при достижении этого размера.

**Назначение:**

Класс Cache представляет собой изменяемое отображение, которое может служить простым кэшем или базовым классом для кэша.

**Использование:**

Создайте экземпляр класса Cache с заданным максимальным размером и опциональной функцией для определения размера объекта. Используйте методы для выполнения операций с кэшем, таких как добавление, извлечение, удаление и проверка наличия элементов.

**Наследование:**

- `collections.abc.MutableMapping`

##### `pop(key, default = __marker)`

Удаляет элемент с указанным ключом из кэша и возвращает его значение, если ключ найден. Если ключ не найден и значение по умолчанию не указано, вызывает KeyError.

**Параметры:**

- `default` (`any`) — значение, возвращаемое в случае отсутствия ключа в кэше
- `key` (`any`) — ключ, который нужно удалить из кэша и вернуть его значение

**Возвращаемое значение:**

- `any` — значение, соответствующее ключу, или значение по умолчанию, если ключ не найден

**Исключения:**

KeyError

**Побочные эффекты:**

Удаление элемента с указанным ключом из кэша

**Примеры:**

Вызов метода pop с указанием ключа и значения по умолчанию

```python
Cache.pop(key, default = __marker)
```

##### `setdefault(key, default = None)`

Устанавливает значение по ключу в кэше. Если ключ уже существует, возвращает его значение. Если ключа нет, устанавливает значение по умолчанию и возвращает его.

**Параметры:**

- `default` (`any`) — значение, которое будет установлено в кэше, если ключ ещё не существует
- `key` (`any`) — ключ, по которому будет установлено значение

**Возвращаемое значение:**

- `any` — возвращает значение, установленное в кэше по ключу, или значение по умолчанию, если ключ не найден

**Примеры:**

Устанавливает значение по ключу в кэше, если ключа нет, то устанавливает значение по умолчанию.

```python

```

### `class LRUCache(Cache)`

### `def cachedmethod(cache, key = keys.methodkey, lock = None, condition = None, info = False)`

Декоратор для обёртывания метода с мемоизацией, сохраняющей результаты в кэше.

**Параметры:**

- `lock` (`N/A`) — Аргумент lock используется для блокировки кэша при доступе к нему.
- `key` (`N/A`) — Ключ для идентификации кэшируемого результата.
- `info` (`bool`) — Флаг для включения дополнительной информации о кэшировании.
- `condition` (`N/A`) — Условие для проверки перед кэшированием результата.
- `cache` (`N/A`) — Кэш для хранения результатов.

**Возвращаемое значение:**

- `N/A` — N/A

**Примеры:**

Пример использования cachedmethod для вычисления чисел Фибоначчи

```python
from cachetools import cachedmethod
@cachedmethod(cache={})
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

Пример использования cachedmethod для кэширования данных PEP

```python
from cachetools import cachedmethod

        return s.read()
```

### `def cached(cache, key = keys.hashkey, lock = None, condition = None, info = False)`

Декоратор для обёртывания функции с мемоизацией, сохраняющей результаты в кэше.

**Параметры:**

- `key` (`N/A`) — Ключ для идентификации кэшируемого результата
- `lock` (`N/A`) — Мьютекс для блокировки при изменении кэша
- `condition` (`N/A`) — Условие для проверки необходимости пересчёта результата
- `info` (`bool`) — Флаг для включения дополнительной информации о попаданиях и промахах в кэш
- `cache` — —

**Примеры:**

Примеры использования декоратора cached с разными типами кэша

```python
from cachetools import cached, LRUCache, TTLCache

# speed up calculating Fibonacci numbers with dynamic programming
@cached(cache={})
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

# cache least recently used Python Enhancement Proposals
@cached(cache=LRUCache(maxsize=32))
def get_pep(num):
    url = 'http://www.python.org/dev/peps/pep-%04d/' % num
    with urllib.request.urlopen(url) as s:
        return s.read()

# cache weather data for no longer than ten minutes
@cached(cache=TTLCache(maxsize=1024, ttl=600))
def get_weather(place):
    return owm.weather_at_place(place).get_weather()
```
