## Функции

### `def _cache(cache, maxsize, typed)`

Функция `_cache` возвращает декоратор для кэширования функций с использованием заданного кэша и параметров.

**Параметры:**

- `cache` (`object`) — объект кэша, который должен поддерживать методы `.get`, `.set`, `.delete` и `.invalidate`.
- `maxsize` (`int`) — максимальное количество элементов в кэше.
- `typed` (`bool`) — если `True`, то кэширование будет различать ключи с разными типами аргументов.

**Примеры:**

```python
# Пример использования _cache с LRUCache
from func import _cache, LRUCache

cache = LRUCache(maxsize=100)
@_cache(cache, maxsize=100, typed=False)
def expensive_function(x):
    # Экспериментально затратная функция
    return x * math.sqrt(random())

# Пример использования _cache с TTLCache
from func import _cache, TTLCache

cache = TTLCache(maxsize=100, ttl=3600)
@_cache(cache, maxsize=100, typed=True)
def expensive_function(x):
    # Экспериментально затратная функция с истечением срока действия
    return x * math.sqrt(random())
```

### `def fifo_cache(maxsize = 128, typed = False)`

Декоратор для обертки функции с кэшированием результатов на основе алгоритма FIFO.

**Параметры:**

- `maxsize` (`int`) — максимальное количество сохраняемых результатов; по умолчанию 128
- `typed` (`bool`) — флаг, определяющий, учитывать ли типы аргументов при кэшировании; по умолчанию False

**Примеры:**

```python
@fifo_cache(maxsize=10)
def compute_expensive_operation(a, b):
    return a * b

result = compute_expensive_operation(2, 3)  # Вычисляется и кэшируется результат
result_cached = compute_expensive_operation(2, 3)  # Результат извлекается из кэша
```

**Смотрите также:**

- `def _cache(cache, maxsize, typed)` — Функция `_cache` возвращает декоратор для кэширования функций с использованием заданного кэша и параметров.

### `def lfu_cache(maxsize = 128, typed = False)`

Декоратор для обертывания функции с кэширующим callable, который сохраняет до `maxsize` результатов на основе алгоритма наименее часто используемых (LFU).

**Параметры:**

- `maxsize` (`int`) — максимальное количество сохраняемых результатов. Если равно `None`, используется отдельный кэш без ограничения размера.
- `typed` (`bool`) — если установлено в `True`, функции с одинаковым аргументом и разными типами будут считаться различными.

**Граничные случаи:**

- Если `maxsize` равно `None`, используется отдельный кэш без ограничения размера.
- Если `maxsize` является вызываемым объектом, он используется как функция `_cache`.

**Примеры:**

```python
@lfu_cache(maxsize=128)
def my_function():
    return some_expensive_operation()
```

**Смотрите также:**

- `def _cache(cache, maxsize, typed)` — Функция `_cache` возвращает декоратор для кэширования функций с использованием заданного кэша и параметров.

### `def lru_cache(maxsize = 128, typed = False)`

Декоратор `lru_cache` оборачивает функцию в мемоизирующий вызываемый объект, который сохраняет до `maxsize` результатов на основе алгоритма наименее недавно использованного (LRU).

**Параметры:**

- `maxsize` (`int`) — максимальное количество результатов, которые будут сохраняться в кэше. Если значение `None`, то нет ограничения по размеру.
- `typed` (`bool`) — если `True`, то кэширование будет различать объекты разных типов с одинаковым значением.

**Граничные случаи:**

- При `maxsize=None` кэш не ограничивается по размеру.
- Если `typed=True`, то кэширование будет различать объекты разных типов с одинаковым значением.

**Примеры:**

```python
@lru_cache(maxsize=128)
def factorial(n):
    if n < 2:
        return 1
    return n * factorial(n - 1)
```

**Смотрите также:**

- `def _cache(cache, maxsize, typed)` — Функция `_cache` возвращает декоратор для кэширования функций с использованием заданного кэша и параметров.

### `def rr_cache(maxsize = 128, choice = random.choice, typed = False)`

Декоратор для обёртывания функции с мемоизирующим вызываемым объектом, который сохраняет до `maxsize` результатов на основе алгоритма случайного замещения (RR).

**Параметры:**

- `maxsize` (`int`) — максимальное количество результатов, которые будут сохраняться. Если `None`, используется бесконечный кэш.
- `choice` (`callable`) — функция для выбора элемента из кэша при переполнении. По умолчанию используется `random.choice`.
- `typed` (`bool`) — если `True`, то кэширование будет различать значения с одинаковым ключом, но разными типами.

**Примеры:**

```python
@rr_cache(maxsize=128)
def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)
```

`_cache`, `RRCache`

### `def ttl_cache(maxsize = 128, ttl = 600, timer = time.monotonic, typed = False)`

Декоратор для обертывания функции с мемоизирующей вызываемым объектом, который сохраняет до `maxsize` результатов на основе алгоритма наименее недавно используемых (LRU) с перцелом времени жизни (TTL).

**Параметры:**

- `maxsize` (`int`) — максимальное количество результатов, которые могут быть закэшированы; если `None`, используется `_UnboundTTLCache`.
- `ttl` (`int`) — время жизни в секундах для каждого элемента в кэше.
- `timer` (`callable`) — функция, которая возвращает текущее время. По умолчанию используется `time.monotonic`.
- `typed` (`bool`) — если True, разрешает кэширование результатов с разными типами аргументов.

**Примеры:**

```python
@ttl_cache(maxsize=128, ttl=600)
def expensive_func(x):
    return x * 2

result = expensive_func(4)  # Вычисляется и кэшируется результат
```

**Смотрите также:**

- `_cache` — Функция для возврата декоратора с использованием заданного кэша и параметров.
