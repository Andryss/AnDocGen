# Модуль `keys.py`


Модуль с функциями для создания ключей кэша.

**Экспорт:**

- `hashkey` — Возвращает ключ кэша для указанных хешируемых аргументов.
- `methodkey` — Возвращает ключ кэша для использования с закэшированными методами.
- `typedkey` — Возвращает типизированный ключ кэша для указанных хешируемых аргументов.
- `typedmethodkey` — Возвращает типизированный ключ кэша для использования с закэшированными методами.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class _HashedTuple(tuple)`

Класс для создания кортежей, которые вычисляют хеш-значение только один раз для каждого элемента.

**Наследование:**

- `tuple`

#### Методы

##### `__add__(other, add = tuple.__add__)`

Складывает два объекта `_HashedTuple` и возвращает новый объект `_HashedTuple`.

**Параметры:**

- `other` (`_HashedTuple`) — второй объект для сложения
- `add` (`callable`) — функция, которая выполняет операцию сложения; по умолчанию `tuple.__add__`

**Возвращаемое значение:**

- `_HashedTuple` — новый объект `_HashedTuple`, содержащий результат сложения двух исходных объектов

**Примеры:**

```python
result = _HashedTuple((1, 2)) + _HashedTuple((3, 4))
print(result)  # Output: (1, 2, 3, 4)
```

##### `__getstate__()`

Возвращает пустой словарь.

**Возвращаемое значение:**

- `dict` — пустой словарь

**Примеры:**

```python
result = _HashedTuple.__getstate__()
print(result)  # {}
```

##### `__hash__(hash = tuple.__hash__)`

Вычисляет хеш-значение объекта `_HashedTuple`.

**Параметры:**

- `hash` — —

**Возвращаемое значение:**

- `int` — вычисленное хеш-значение

**Примеры:**

```python
# Пример использования
my_tuple = _HashedTuple((1, 2, 3))
print(my_tuple.__hash__())  # Выведет хеш-значение my_tuple
```

##### `__radd__(other, add = tuple.__add__)`

Объединяет объект `_HashedTuple` с другим объектом справа налево.

**Параметры:**

- `other` (`any`) — объект, который будет слева от текущего `_HashedTuple`
- `add` (`callable`) — функция для объединения двух объектов (по умолчанию `tuple.__add__`)

**Возвращаемое значение:**

- `_HashedTuple` — новый объект `_HashedTuple`, содержащий элементы из `other` и текущего `_HashedTuple`

**Примеры:**

```python
result = _HashedTuple([1, 2]) + (3, 4)  # result будет экземпляром _HashedTuple([1, 2, 3, 4])
```

## Функции

### `def hashkey(*args, **kwargs)`

Возвращает ключ кэша для указанных хешируемых аргументов.

**Параметры:**

- `*args` — позиционные аргументы, которые должны быть хешируемыми
- `**kwargs` — именованные аргументы, которые должны быть хешируемыми

**Возвращаемое значение:**

- `_HashedTuple` — кортеж, содержащий все хешируемые аргументы, отсортированные и закодированные для использования в качестве ключа кэша

**Примеры:**

```python
hashkey('a', 'b')  # вернет _HashedTuple(('a', 'b'))
hashkey(key='value')  # вернет _HashedTuple((_kwmark, ('key', 'value')))
hashkey(1, 2, key=3)  # вернет _HashedTuple((1, 2, _kwmark, ('key', 3)))
```

### `def typedkey(*args, **kwargs)`

Возвращает типизированный ключ кэша для указанных хешируемых аргументов.

**Параметры:**

- `*args` — позиционные аргументы
- `**kwargs` — именнованные аргументы

**Возвращаемое значение:**

- `_HashedTuple` — типизированный ключ кэша

**Примеры:**

```python
# Пример использования
result = typedkey(1, 2, x=3, y=4)
print(result)  # выводит типизированный ключ кэша
```

### `def methodkey(*args, **kwargs)`

Возвращает ключ кэша для использования с закэшированными методами.

**Параметры:**

- `*args` (`any`) — позиционные аргументы
- `**kwargs` (`any`) — именованные аргументы

**Возвращаемое значение:**

- `int` — ключ кэша

**Примеры:**

```python
key = methodkey('example', arg1=123)
```

### `def typedmethodkey(*args, **kwargs)`

Возвращает типизированный ключ кэша для использования с закэшированными методами.

**Параметры:**

- `*args` — —
- `**kwargs` — —

**Возвращаемое значение:**

- `str` — типизированный ключ кэша

**Примеры:**

```python
typedmethodkey('arg1', 'arg2')
```
