### `class Cache(collections.abc.MutableMapping)`

Мутабельное отображение, используемое как простой кэш или базовый класс для кэшей.

**Наследование:**

- `collections.abc.MutableMapping`

#### Методы

##### `__delitem__(key)`

Удаляет элемент из кэша по ключу.

**Параметры:**

- `key` — ключ, по которому удаляется элемент из кэша

**Побочные эффекты:**

Метод изменяет состояние объекта Cache, удаляя элемент и обновляя текущий размер.

##### `__contains__(key)`

Проверяет, существует ли ключ в кэше.

**Параметры:**

- `key` (`any`) — ключ для проверки

**Возвращаемое значение:**

- `bool` — True если ключ существует, False иначе

**Примеры:**

```python
cache = Cache()
cache[1] = 'value'
print(1 in cache)  # True
print(2 in cache)  # False
```

##### `__getitem__(key)`

Возвращает значение по ключу из кэша или вызывает метод __missing__ при отсутствии ключа.

**Параметры:**

- `key` (`object`) — ключ, для которого нужно вернуть значение

**Возвращаемое значение:**

- `value` — значение, связанное с ключом

**Параметры:**

- `maxsize` (`int`) — максимальный размер кеша
- `getsizeof` (`callable, optional`) — функция для определения размера объектов, по умолчанию None

**Побочные эффекты:**

Инициализирует внутренние словари и переменные для управления кешем.

##### `__setitem__(key, value)`

Задает значение для указанного ключа в кэше и обновляет его размер.

**Параметры:**

- `key` (`any`) — ключ, который нужно установить
- `value` (`any`) — значение, которое нужно установить

**Исключения:**

- `ValueError` — если размер значения превышает максимальный размер кэша

**Граничные случаи:**

- Если значение уже существует в кэше и его новый размер больше предыдущего, старое значение удаляется
- Если размер значения меньше или равен размеру текущего значения для данного ключа, не происходит удаления других элементов
- Если размер нового значения превышает максимальный размер кэша, удаляются элементы до тех пор, пока новый элемент не влезет

**Побочные эффекты:**

Модифицирует содержимое и размер кэша.

**Примеры:**

```python
cache = Cache(10)
cache['a'] = 5
```

##### `get(key, default = None)`

Извлекает значение по указанному ключу из кэша, возвращая его или значение по умолчанию, если ключ отсутствует.

**Параметры:**

- `key` (`str`) — ключ для извлечения значения
- `default` (`any, optional`) — значение по умолчанию, возвращаемое при отсутствии ключа (по умолчанию `None`)

**Возвращаемое значение:**

- `any` — значение, связанное с ключом или значение по умолчанию

**Примеры:**

```python
cache = Cache()
cache.set('example_key', 'value')
result = cache.get('example_key')  # result == 'value'
result = cache.get('nonexistent_key', 'default_value')  # result == 'default_value'
```

##### `pop(key, default = __marker)`

Удаляет элемент из кэша по заданному ключу и возвращает его значение. Если ключ не существует, возвращает указанный默认值 или выбрасывает исключение `KeyError`.

**Параметры:**

- `key` (`Any`) — ключ элемента, который нужно удалить
- `default` (`Optional[Any]`) — значение по умолчанию, возвращаемое если ключ не найден (по умолчанию — выбрасывается исключение)

**Возвращаемое значение:**

- `Any` — значение удаленного элемента или значение по умолчанию

**Исключения:**

- `KeyError` — если ключ не найден и не указано значение по умолчанию

**Граничные случаи:**

- Если ключ не существует и не указано значение по умолчанию, выбрасывается исключение `KeyError`
- Если ключ существует, его значение удаляется из кэша и возвращается

**Побочные эффекты:**

Удаляет элемент из кэша.

**Примеры:**

```python
cache = Cache()
cache['a'] = 10
print(cache.pop('a'))  # Output: 10

try:
    print(cache.pop('b'))
except KeyError as e:
    print(e)  # Output: 'b' not in Cache

print(cache.pop('b', None))  # Output: None
```

##### `setdefault(key, default = None)`

Возвращает значение по ключу, если ключ существует в словаре. Если ключ отсутствует, добавляет его с указанным значением и возвращает это значение.

**Параметры:**

- `key` (`object`) — ключ для поиска или добавления
- `default` (`object`) — значение, которое будет установлено для ключа, если он отсутствует (по умолчанию `None`)

**Возвращаемое значение:**

- `object` — текущее значение ключа или установленное значение

**Примеры:**

```python
cache = Cache()
value = cache.setdefault('a', 10)
print(value)  # Выведет 10, так как 'a' отсутствует в словаре

value = cache.setdefault('a', 20)
print(value)  # Выведет 10, так как 'a' уже существует в словаре
```

##### `__len__(cache_len = Cache.__len__)`

Возвращает количество элементов в кэше, учитывая время жизни.

**Параметры:**

- `cache_len` (`function`) — функция для получения длины кэша, которая должна принимать объект кэша и возвращать его длину

**Возвращаемое значение:**

class MyCache(Cache):
    def __init__(self, max_size):
        super().__init__()
        self.max_size = max_size

    def __getitem__(self, key):
        return self._data[key]

    def __setitem__(self, key, value):
        if len(self) >= self.max_size:
            oldest_key = min(self.keys(), key=lambda k: self[k])
            del self[oldest_key]
        self._data[key] = value

    def __delitem__(self, key):
        del self._data[key]

    def __iter__(self):
        return iter(self._data)

    def __len__(self):
        return len(self._data)

# Использование

cache['b'] = 2

## Функции

### `def cached(cache, key = keys.hashkey, lock = None, condition = None, info = False)`

Декоратор для оборачивания функции с обертывающейся вызываемой, которая сохраняет результаты в кэше.

**Параметры:**

- `cache` (`Cache`) — объект кэша, который будет использоваться для хранения результатов.
- `key` (`Callable, optional`) — функция, которая вычисляет ключ для кэширования. По умолчанию используется `keys.hashkey`.
- `lock` (`Lock, optional`) — объект блокировки, используемый для обеспечения атомарности при доступе к кэшу.
- `condition` (`Callable, optional`) — функция, которая возвращает `True`, если выполнение функции должно быть отложено. По умолчанию используется `None`.
- `info` (`bool, optional`) — если `True`, декоратор вернёт объект `_CacheInfo`, содержащий статистику использования кэша (колличество попаданий и промахов). По умолчанию используется `False`.

**Примеры:**

```python
@cached(cache=cache_instance, key=lambda *args: args)
def my_function(a, b):
    return a + b
```

### `def cachedmethod(cache, key = keys.methodkey, lock = None, condition = None, info = False)`

Декоратор для обертывания метода с кэширующим вызовом, сохраняющим результаты в кэше.

**Параметры:**

- `cache` (`callable`) — функция, возвращающая мутабельное отображение для хранения результатов.
- `key` (`callable, опционально`) — функция, генерирующая ключ для кэша. По умолчанию используется `keys.methodkey`.
- `lock` (`Lock, опционально`) — объект блокировки для потокобезопасности.
- `condition` (`Condition, опционально`) — объект условия для блокировки и ожидания.
- `info` (`bool, опционально`) — если True, возвращается объект `_CacheInfo` с информацией о кэше. По умолчанию False.

**Исключения:**

- `TypeError` — если `cache(self)` не возвращает мутабельное отображение.

**Граничные случаи:**

- Если `info` равно True, метод вернет объект `_CacheInfo`, содержащий информацию о кэше.
- Если `lock` или `condition` не переданы, они не будут использоваться для обеспечения потокобезопасности.

**Примеры:**

```python
class MyClass:
    @cachedmethod(cache=dict)
    def compute(self, a, b):
        return a + b
```

- `keys.methodkey`
- `_CacheInfo`
