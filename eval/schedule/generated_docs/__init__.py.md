Класс для представления периодических задач с расписанием и выполнением.

#### Методы

##### `__init__(interval: int, scheduler: Optional[Scheduler] = None)`

Инициализирует объект `Job` с параметрами интервала и расписания.

**Параметры:**

- `interval` (`int`) — время между запусками задания в секундах.
- `scheduler` (`Optional[Scheduler]`) — расписание, с которым будет зарегистрировано задание. По умолчанию `None`.

**Примеры:**

```python
job = Job(interval=3600, scheduler=my_scheduler)
```

##### `__lt__(other) -> bool`

Сравнивает два объекта Job и возвращает True, если время следующего выполнения текущего объекта меньше, чем у другого объекта.

**Параметры:**

- `other` (`Job`) — объект Job для сравнения

**Возвращаемое значение:**

- `bool` — True, если время следующего выполнения текущего объекта меньше, чем у другого объекта

**Примеры:**

```python
job1 = Job(next_run=datetime(2023, 10, 1))
job2 = Job(next_run=datetime(2023, 10, 2))
print(job1 < job2)  # True
```

##### `_correct_utc_offset(moment: datetime.datetime, fixate_time: bool) -> datetime.datetime`

Исправляет ошибки с UTC-смещением для заданного времени.

**Параметры:**

- `moment` (`datetime.datetime`) — исходное время с смещением UTC
- `fixate_time` (`bool`) — флаг, определяющий, нужно ли попытаться сохранить компонент времени (часы, минуты, секунды)

**Возвращаемое значение:**

- `datetime.datetime` — исправленное время с корректным UTC-смещением

**Граничные случаи:**

1. Если `at_time_zone` равно None, возвращается исходное время без изменений.
2. Если время после нормализации не изменилось, возвращается исходное время без изменений.
3. Если флаг `fixate_time` установлен в False, время не корректируется.
4. Если попытка вернуться к начальному времени с учётом разницы смещений приводит к ошибке (например, во время перехода на летнее время), время сдвигается на смещение назад.

**Примеры:**

```python
job = Job(at_time_zone=some_timezone)
corrected_time = job._correct_utc_offset(datetime.now(), fixate_time=True)
```

##### `_decode_datetimestr(datetime_str: str, formats: List[str]) -> Optional[datetime.datetime]`

Декодирует строку в объект `datetime` по заданным форматам.

**Параметры:**

- `datetime_str` (`str`) — строка с датой и временем

**Возвращаемое значение:**

- `Optional[datetime.datetime]` — объект `datetime` если возможно, иначе None

**Примеры:**


##### `run()`

Запускает задание и немедленно перезаписывает его.

Если срок действия задания истек (конфигурируется с помощью `.until()`), задание не выполняется и возвращается CancelJob. Если следующая запланированная выполнение превышает срок действия задания, после выполнения возвращается CancelJob. В этом последнем случае CancelJob имеет приоритет над любым другим возвращаемым значением.

:return: Возвращает значение, возвращенное функцией `job_func`, или CancelJob если срок действия задания истек.

**Возвращаемое значение:**

- `Union[return type of job_func, CancelJob]` — результат выполнения функции `job_func`, или CancelJob если срок действия задания истек

**Граничные случаи:**

- Если срок действия задания истек перед его выполнением, возвращается CancelJob.
- Если следующее запланированное выполнение превышает срок действия задания, после выполнения возвращается CancelJob.

**Побочные эффекты:**

Задание регистрируется как выполненное и переаппланировывается.

**Примеры:**

```python
job = Job(job_func=my_job_function)
result = job.run()
```

##### `to(latest: int)`

Расписание работы задания на нерегулярный (случайный) интервал.

Задание будет выполняться с интервалом, который случайно изменяется от значения, указанного в `every` до `latest`. Определенный диапазон включительно на обоих концах. Например, `every(A).to(B).seconds` выполняет функцию задания каждые N секунд так, что A <= N <= B.

**Параметры:**

- `latest` (`int`) — максимальный интервал между случайными запусками задания

**Возвращаемое значение:**

- `Job` — экземпляр вызванного задания

**Примеры:**

```python
job = every(5).to(10).seconds  # Задание будет выполняться каждые N секунд, где 5 <= N <= 10
```

##### `until(until_time: Union[datetime.datetime, datetime.timedelta, datetime.time, str])`

Запланировывает выполнение задачи до указанного момента.

Задача отменяется каждый раз, когда вычисляется следующий запуск и он оказывается после `until_time`. Задача также отменяется сразу перед запуском, если текущее время уже превышает `until_time`. Это может произойти, если задание было запланировано на выполнение до `until_time`, но выполняется после этого времени.

Если `until_time` — это время в прошлом, выбрасывается ошибка `ScheduleValueError`.

:param until_time: Момент в будущем, представляющий собой максимальное время, когда задача может быть выполнена. Если предоставлено только время, дата устанавливается на сегодня. Принимаются следующие форматы:

   - datetime.datetime
   - datetime.timedelta
   - datetime.time
   - Строка в одном из следующих форматов: "%Y-%m-%d %H:%M:%S", "%Y-%m-%d %H:%M", "%Y-%m-%d", "%H:%M:%S", "%H:%M" как определено поведением `strptime()`. Если передается недопустимый формат строки, выбрасывается ошибка `ScheduleValueError`.

:return: Запущенная задача

**Параметры:**

- `until_time` (`Union[datetime.datetime, datetime.timedelta, datetime.time, str]`) — момент в будущем, представляющий собой максимальное время, когда задача может быть выполнена. Если предоставлено только время, дата устанавливается на сегодня. Принимаются следующие форматы: datetime.datetime, datetime.timedelta, datetime.time, строка в одном из форматов "%Y-%m-%d %H:%M:%S", "%Y-%m-%d %H:%M", "%Y-%m-%d", "%H:%M:%S", "%H:%M" как определено поведением `strptime()`.

**Возвращаемое значение:**

- `Job` — запущенная задача

**Исключения:**

- `ScheduleValueError` — если `until_time` в прошлом
- `TypeError` — если передан неверный тип параметра

**Примеры:**

```python
from job import Job

# Запланировать задачу на выполнение до определенного момента времени
job = Job().until(datetime.datetime(2023, 12, 31, 23, 59, 59))

# Запланировать задачу на выполнение через определенное количество времени
job = Job().until(datetime.timedelta(days=1))

# Запланировать задачу на выполнение в определенное время сегодня
job = Job().until("23:59")

# Запланировать задачу на выполнение в определенное время в указанную дату
job = Job().until("2024-01-01 23:59")
```

### `class Scheduler`

Класс для планирования и управления задачами.

#### Методы

##### `__init__() -> None`

Инициализирует экземпляр класса Scheduler.

**Примеры:**

```python
scheduler = Scheduler()
```

##### `_run_job(job: 'Job') -> None`

Запускает задание и обрабатывает его результат.

**Параметры:**

- `job` (`Job`) — объект задания для выполнения

##### `cancel_job(job: 'Job') -> None`

Отменяет запланированную задачу.

**Параметры:**

- `job` (`Job`) — задача, которая должна быть отменена

**Побочные эффекты:**

Изменяет внутренний список запланированных задач.

**Примеры:**

```python
scheduler.cancel_job(job)
```

##### `clear(tag: Optional[Hashable] = None) -> None`

Удаляет запланированные задания, отмеченные данным тегом, или все задания, если тег не указан.

**Параметры:**

- `tag` (`Optional[Hashable]`) — идентификатор, используемый для идентификации подмножества задач для удаления

**Побочные эффекты:**

Изменяет структуру данных `self.jobs`, удаляя отмеченные задания.

**Примеры:**

```python
scheduler.clear(tag='some_tag')
scheduler.clear()
```

##### `every(interval: int = 1) -> 'Job'`

Расписание новой периодической задачи.

**Параметры:**

- `interval` (`int`) — количество определенного временного периода

**Возвращаемое значение:**

- `Job` — неподготовленная :class:`Job <Job>`

**Примеры:**

```python
job = Scheduler.every(10)  # Расписание новой периодической задачи с интервалом в 10 единиц времени
```

##### `get_jobs(tag: Optional[Hashable] = None) -> List['Job']`

Получает задачи, отмеченные заданным тегом, или все задачи, если тег не указан.

**Параметры:**

- `tag` (`Optional[Hashable]`) — идентификатор, используемый для идентификации подмножества задач для извлечения

**Возвращаемое значение:**

- `List['Job']` — список задач, отмеченных заданным тегом или все задачи

**Примеры:**

```python
# Получение всех задач
jobs = scheduler.get_jobs()

# Получение задач с конкретным тегом
filtered_jobs = scheduler.get_jobs(tag='important')
```

##### `get_next_run(tag: Optional[Hashable] = None) -> Optional[datetime.datetime]`

Возвращает дату и время следующего запуска задания, отфильтрованного по опциональному тегу.

**Параметры:**

- `tag` (`Optional[Hashable]`) — Тег для фильтрации следующего запуска. Если не указан, возвращается дата и время следующего запуска без учета тегов.

**Возвращаемое значение:**

- `Optional[datetime.datetime]` — Дата и время следующего запуска задания или None, если нет запланированных заданий.

**Примеры:**

```python
scheduler = Scheduler()
# Получение даты и времени следующего запуска без фильтрации по тегу
next_run = scheduler.get_next_run()

# Получение даты и времени следующего запуска с фильтрацией по тегу 'important'
next_run_filtered = scheduler.get_next_run(tag='important')
```

##### `idle_seconds() -> Optional[float]`

Возвращает количество секунд до следующего запуска задачи или None, если нет запланированных задач.

**Возвращаемое значение:**

- `Optional[float]` — количество секунд до следующего запуска задачи или None, если нет запланированных задач

**Примеры:**

```python
scheduler = Scheduler()
print(scheduler.idle_seconds())
```

##### `run_all(delay_seconds: int = 0) -> None`

Запускает все задания независимо от того, запланированы они или нет. Добавляет задержку между каждым выполненным заданием.

**Параметры:**

- `delay_seconds` (`int`) — Задержка добавляемая между каждым выполненными заданием (по умолчанию 0)

**Побочные эффекты:**

Запускает все задания, что может изменить состояние системы.

**Примеры:**

```python
scheduler = Scheduler()
scheduler.run_all(delay_seconds=5)
```

##### `run_pending() -> None`

Запускает все задания, которые должны запуститься.

**Примеры:**

```python
scheduler = Scheduler()
# Регистрируем некоторые задания
scheduler.add_job(my_task, trigger='interval', minutes=1)
# Запускаем все готовые к выполнению задания
scheduler.run_pending()
```

### `def repeat(job, *args, **kwargs)`

Декоратор для планирования нового периодического задания.

Любые дополнительные аргументы передаются запланированной функции при выполнении задания.

**Параметры:**

- `job` (`Job`) — объект задания
- `*args` — любые позиционные аргументы, которые будут переданы запланированной функции
- `**kwargs` — любые именованные аргументы, которые будут переданы запланированной функции

**Примеры:**

```python
@repeat(job=some_job)
def my_function():
    print("This function will run periodically.")
```

### `def _move_to_next_weekday(moment: datetime.datetime, weekday: str)`

Перемещает заданное время戳 на ближайший указанный день недели. Может быть этой же неделей или следующей. Если время戳 уже находится на указанном дне недели, он не перемещается.

**Параметры:**

- `moment` (`datetime.datetime`) — Временной戳 для перемещения
- `weekday` (`str`) — День недели ('monday', 'tuesday', ..., 'sunday')

**Возвращаемое значение:**

- `datetime.datetime` — Перемещенный временной戳

**Примеры:**

```python
from datetime import datetime

timestamp = datetime(2023, 10, 5, 14, 0, 0)  # Понедельник, 5 октября 2023 года
next_monday = _move_to_next_weekday(timestamp, 'monday')
print(next_monday)  # Понедельник, 9 октября 2023 года

timestamp = datetime(2023, 10, 6, 14, 0, 0)  # Вторник, 6 октября 2023 года
next_monday = _move_to_next_weekday(timestamp, 'monday')
print(next_monday)  # Понедельник, 9 октября 2023 года
```

- `_weekday_index`
