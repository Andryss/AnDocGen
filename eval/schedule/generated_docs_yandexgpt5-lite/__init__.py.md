# Модуль `__init__.py`


Модуль schedule для Python, который позволяет планировать периодические задания с использованием простого и понятного синтаксиса.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class CancelJob`

Класс CancelJob.

**Назначение:**

Может быть возвращен из задания для отмены его расписания.

### `class IntervalError(ScheduleValueError)`

Класс IntervalError, наследуемый от ScheduleValueError, предназначен для обработки ошибок, связанных с неправильным интервалом

**Назначение:**

Представляет ошибку, возникающую при использовании некорректного интервала

**Наследование:**

- `ScheduleValueError`

### `class Job`

Класс Job представляет собой периодическое задание, которое выполняется через заданные интервалы времени.

**Назначение:**

Класс для представления периодических заданий, используемых планировщиком Scheduler.

**Использование:**

Создайте экземпляр класса Job с заданным интервалом и опциональным планировщиком. Настройте задание с помощью методов класса и зарегистрируйте его в экземпляре Scheduler с помощью метода do().

#### Методы

##### `__lt__(other) -> bool`

Сравнивает два объекта PeriodicJobs по времени их следующего запуска и возвращает True, если текущий объект должен идти раньше, иначе False

**Параметры:**

- `other` (`PeriodicJobs`) — Сравнение объекта PeriodicJobs с другим объектом для определения, какой из них должен идти раньше по расписанию

**Возвращаемое значение:**

- `bool` — True, если текущий объект должен идти раньше по расписанию, чем объект other, иначе False

**Примеры:**

Сравнение времени следующего запуска двух объектов PeriodicJobs

```python
Job.__lt__(other)
```

Инициализирует объект Job с заданным интервалом паузы и опциональным планировщиком.

**Параметры:**

- `scheduler` (`Scheduler`) — Планировщик для регистрации объекта Job
- `interval` (`int`) — Интервал паузы между запусками

```python

```

##### `_correct_utc_offset(moment: datetime.datetime, fixate_time: bool) -> datetime.datetime`

Корректирует ошибки в UTC-смещении для заданной даты и времени, сохраняя или не сохраняя время в зависимости от параметра fixate_time.

**Параметры:**

- `moment` (`datetime.datetime`) — Корректирует ошибки в UTC-смещении для заданной даты и времени
- `fixate_time` (`bool`) — Флаг, указывающий, нужно ли фиксировать время при корректировке UTC-смещения

**Возвращаемое значение:**

- `datetime.datetime` — Дата и время с исправленным UTC-смещением

**Примеры:**

Корректировка UTC-смещения с фиксацией времени

```python
Job._correct_utc_offset(moment, fixate_time=True)
```

Корректировка UTC-смещения без фиксации времени

```python
Job._correct_utc_offset(moment, fixate_time=False)
```

##### `_decode_datetimestr(datetime_str: str, formats: List[str]) -> Optional[datetime.datetime]`

Декодирует строку в формат datetime, используя заданные форматы. Если ни один формат не подходит, возвращает None.

**Параметры:**

- `datetime_str` (`str`) — Строка, которую нужно декодировать в формат datetime.
- `formats` (`List[str]`) — Список форматов для попытки декодирования.

**Возвращаемое значение:**

- `Optional[datetime.datetime]` — Декодированная дата в формате datetime.datetime или None, если декодирование не удалось.

**Исключения:**

ValueError

**Граничные случаи:**

Если ни один из форматов не подходит, возвращает None.

**Примеры:**

Попытка декодирования строки даты с использованием нескольких форматов.

```python
Job._decode_datetimestr('2023-10-10', ['%Y-%m-%d', '%d.%m.%Y'])
```

##### `at(time_str: str, tz: Optional[str] = None)`

Устанавливает конкретное время, в которое должно быть выполнено задание.

**Параметры:**

- `tz` (`str`) — Часовой пояс, который задаёт временную метку. Может быть строкой, которую можно разобрать с помощью pytz.timezone(), или объектом pytz.BaseTzInfo.
- `time_str` (`str`) — Строка в одном из следующих форматов: для ежедневных заданий — HH:MM:SS или HH:MM; для ежечасных заданий — MM:SS или :MM; для ежеминутных заданий — :SS.

**Возвращаемое значение:**

- `Job` — Вызванный экземпляр задания

**Исключения:**

ScheduleValueError

**Граничные случаи:**

Проверяет допустимость формата времени в зависимости от выбранной единицы повторения (дни, часы, минуты).

**Примеры:**

Установка времени для ежедневного задания

```python
job.at('12:30')
```

Установка времени для ежечасного задания с указанием часового пояса

```python
job.at(':30', tz='Europe/Moscow')
```

##### `until(until_time: Union[datetime.datetime, datetime.timedelta, datetime.time, str])`

Планирует задание для выполнения до указанного момента. Задание отменяется, если следующий запуск будет после until_time или если текущее время уже после until_time.

**Параметры:**

- `until_time` (`Union[datetime.datetime, datetime.timedelta, datetime.time, str]`) — Момент в будущем, представляющий последнее время, когда задание может быть запущено. Если указано только время, дата устанавливается на сегодняшний день. Допустимые форматы: datetime.datetime, datetime.timedelta, datetime.time, строка в одном из форматов, определённых strptime() поведением.

**Возвращаемое значение:**

- `The invoked job instance` — Вызванный экземпляр задания

**Исключения:**

ScheduleValueError

**Примеры:**

Запланировать задание, которое будет выполняться до указанного времени в формате '%Y-%m-%d %H:%M:%S'.

```python
job.until('2023-10-10 12:00:00')
```

Запланировать задание, которое будет выполняться до указанного времени в формате '%H:%M'.

```python
job.until('12:00')
```

##### `run()`

Запускает задание и немедленно перепланировать его. Если срок выполнения задания истёк (настроен с помощью .until()), задание не выполняется, и немедленно возвращается CancelJob.
