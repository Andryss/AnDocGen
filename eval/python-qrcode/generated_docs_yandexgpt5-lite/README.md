# python-qrcode

=============================

## Пакеты

| Пакет | Модулей | Описание |
|--------|-------------|--------------|
| [qrcode/](qrcode/README.md) | 10 | Модуль python-qrcode для генерации QR-кодов. Содержит функции для создания QR-кодов и примеры их использования. |
| [compat/](qrcode/compat/README.md) | 3 | Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Для установки используется команда pip install qrcode. Для более продвинутой работы с изображениями необходимо установить зависимость pil. |
| [image/](qrcode/image/README.md) | 6 | Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Для работы с изображениями требуется установка зависимости 'pil', которая позволяет использовать библиотеку pillow для генерации изображений. Модуль включает в себя функцию make для быстрого создания QR-кодов и класс QRCode для более тонкой настройки параметров генерации. |
| [styles/](qrcode/image/styles/README.md) | 2 | Модуль python-qrcode предназначен для генерации QR-кодов. Может использоваться из командной строки или в Python для создания изображений QR-кодов. |
| [moduledrawers/](qrcode/image/styles/moduledrawers/README.md) | 4 | Модуль для ленивого импорта рисовальщиков PIL с предупреждением об устаревании. Импорт рисовальщиков PIL из этого модуля разрешён для обеспечения обратной совместимости, но будет вызывать DeprecationWarning. Модуль будет удалён в версии 9.0. |
