# Модуль `qrcode/image/__init__.py`


Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Для работы с изображениями требуется установка зависимости 'pil', которая позволяет использовать библиотеку pillow для генерации изображений. Модуль включает в себя функцию make для быстрого создания QR-кодов и класс QRCode для более тонкой настройки параметров генерации.
