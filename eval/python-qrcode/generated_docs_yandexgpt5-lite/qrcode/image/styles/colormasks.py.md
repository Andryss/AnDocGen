# Модуль `qrcode/image/styles/colormasks.py`


Модуль содержит классы для создания различных цветовых масок для QR-кодов.

**Содержание:**

- [Классы](#классы)

## Классы

### `class HorizontalGradiantColorMask(QRColorMask)`

Класс HorizontalGradiantColorMask для создания горизонтального градиента цветов в QR-кодах.

**Назначение:**

Создаёт маску горизонтального градиента цветов для использования в QR-кодах, заполняя передний план градиентом, который простирается слева направо.

**Использование:**

Создайте экземпляр класса HorizontalGradiantColorMask с заданными цветами фона, слева и справа. Используйте метод get_fg_pixel для получения цвета пикселя в изображении на основе координат x и y.

**Наследование:**

- `QRColorMask`

#### Методы

##### `__init__(back_color = (255, 255, 255), left_color = (0, 0, 0), right_color = (0, 0, 255))`

Инициализация объекта HorizontalGradiantColorMask с заданными цветами фона, слева и справа.

**Параметры:**

- `back_color` (`tuple`) — цвет фона
- `left_color` (`tuple`) — цвет слева
- `right_color` (`tuple`) — цвет справа

**Примеры:**

Инициализация объекта с заданными цветами

```python
HorizontalGradiantColorMask.__init__(back_color = (255, 255, 255), left_color = (0, 0, 0), right_color = (0, 0, 255))
```

##### `get_fg_pixel(image, x, y)`

Возвращает цвет пикселя в изображении на основе координат x и y

**Параметры:**

- `image` (`Image`) — Изображение, в котором необходимо получить цвет пикселя
- `x` (`int`) — Координата x пикселя
- `y` (`int`) — Координата y пикселя

**Возвращаемое значение:**

- `color` — Цвет пикселя после интерполяции между left_color и right_color

**Примеры:**

Получить цвет пикселя на основе координат x и y в изображении

```python
HorizontalGradiantColorMask.get_fg_pixel(image, x, y)
```

### `class QRColorMask`

**Назначение:**

Используется для раскрашивания QR-кода, применяя цветовую маску к изображению и изменяя цвета пикселей в соответствии с алгоритмом.

**Использование:**

Необходимо инициализировать маску цвета для стилизованного изображения с помощью метода initialize, а затем применить маску к изображению с помощью метода apply_mask.

- `n2` (`N/A`) — Второй аргумент

**Возвращаемое значение:**
