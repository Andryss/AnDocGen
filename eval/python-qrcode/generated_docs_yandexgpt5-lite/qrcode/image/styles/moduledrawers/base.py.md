# Модуль `qrcode/image/styles/moduledrawers/base.py`


Модуль для отрисовки QR-кодов на изображениях.

**Содержание:**

- [Классы](#классы)

## Классы

### `class QRModuleDrawer(abc.ABC)`

Класс QRModuleDrawer используется для отрисовки модулей QR-кода на изображениях. Для этого требуется функция drawrect(self, box, is_active), которая рисует прямоугольник в заданной области и учитывает активность модуля. Также может потребоваться реализация функции initialize для настройки значений, связанных с классом Image.

**Назначение:**

Класс QRModuleDrawer предназначен для отрисовки модулей QR-кода на изображениях.

**Использование:**

Необходимо создать экземпляр класса QRModuleDrawer и вызвать методы initialize и drawrect для инициализации и отрисовки модулей QR-кода.

##### `drawrect(box, is_active) -> None`

Отрисовывает прямоугольник.

**Параметры:**

- `box` (`N/A`) — Прямоугольник для отрисовки
- `is_active` (`N/A`) — Указывает, активен ли прямоугольник

**Возвращаемое значение:**

- `None` — N/A

**Примеры:**

Вызов метода drawrect с параметрами box и is_active

```python
QRModuleDrawer.drawrect(box, is_active)
```

**Возвращаемое значение:**
