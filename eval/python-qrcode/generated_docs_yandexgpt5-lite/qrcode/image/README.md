## Модули

| Модуль | Описание |
|--------|--------------|
| [__init__.py](__init__.py.md) | Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Для работы с изображениями требуется установка зависимости 'pil', которая позволяет использовать библиотеку pillow для генерации изображений. Модуль включает в себя функцию make для быстрого создания QR-кодов и класс QRCode для более тонкой настройки параметров генерации. |
| [base.py](base.py.md) | Модуль содержит базовые классы для работы с изображениями QR-кодов: BaseImage и BaseImageWithDrawer. |
| [pil.py](pil.py.md) | Модуль для работы с изображениями в формате PIL в целях генерации QR-кодов. |
| [pure.py](pure.py.md) | Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Он использует библиотеку pypng для создания PNG-файлов и может отображать QR-коды непосредственно в консоли. Для более широких возможностей по работе с изображениями требуется установка зависимости pil, которая устанавливает pillow. |
| [styledpil.py](styledpil.py.md) | Модуль StyledPilImage для работы с QR-кодами в формате PIL в проекте python-qrcode. |
| [svg.py](svg.py.md) | Модуль для создания SVG-изображений QR-кодов. |
