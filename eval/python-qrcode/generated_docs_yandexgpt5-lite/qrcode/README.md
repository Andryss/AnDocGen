# qrcode

[← К проекту](../README.md)

## Модули

| Модуль | Описание |
|--------|--------------|
| [__init__.py](__init__.py.md) | Модуль python-qrcode для генерации QR-кодов. Содержит функции для создания QR-кодов и примеры их использования. |
| [LUT.py](LUT.py.md) | Модуль для генерации QR-кодов на чистом Python. Может использоваться для создания QR-кодов из командной строки или в Python-приложениях. |
| [__main__.py](__main__.py.md) | Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Он может генерировать PNG-файлы и выводить QR-коды прямо в консоль. Для более продвинутого использования можно использовать класс QRCode с настраиваемыми параметрами. |
| [base.py](base.py.md) | Модуль содержит функции и классы для работы с QR-кодами, включая работу с полиномами и блоками RS. |
| [console_scripts.py](console_scripts.py.md) | Модуль для работы с QR-кодами, включая конвертацию данных в QR-код через командную строку и функции для работы с изображениями QR-кодов. |
| [constants.py](constants.py.md) | Модуль python-qrcode предназначен для генерации QR-кодов. Содержит класс QRCode для создания QR-кодов с настройками и константы, такие как ERROR_CORRECT_L, которые используются для настройки коррекции ошибок. Для работы модуля требуется установка зависимостей, например, pypng для генерации PNG файлов или pillow для более продвинутой работы с изображениями. |
| [exceptions.py](exceptions.py.md) | Модуль python-qrcode содержит класс DataOverflowError для обработки ошибок переполнения данных. |
| [main.py](main.py.md) | Модуль python-qrcode для генерации QR-кодов. Содержит функции для проверки параметров и классы для создания QR-кодов с различными настройками. |
| [release.py](release.py.md) | Модуль предоставляет точки входа zest.releaser для использования при выпуске новых версий qrcode. |
| [util.py](util.py.md) | Модуль содержит функции и классы для работы с QR-кодами, включая обработку данных, расчёт параметров и создание QR-кодов. |
