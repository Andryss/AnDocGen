# Модуль `qrcode/compat/png.py`


Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Он позволяет создавать QR-коды из различных типов данных и сохранять их в формате PNG. Для более продвинутого использования можно использовать класс QRCode для настройки параметров QR-кода.
