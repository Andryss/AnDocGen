# Модуль `qrcode/compat/etree.py`


Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Он позволяет создавать QR-коды из различных типов данных и сохранять их в формате PNG или выводить в консоль. Для работы с модулем достаточно выполнить команду pip install qrcode. Для расширенных возможностей работы с изображениями требуется установка зависимости pil.
