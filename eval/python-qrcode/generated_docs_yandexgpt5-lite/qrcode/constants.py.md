# Модуль `qrcode/constants.py`


Модуль python-qrcode предназначен для генерации QR-кодов. Содержит класс QRCode для создания QR-кодов с настройками и константы, такие как ERROR_CORRECT_L, которые используются для настройки коррекции ошибок. Для работы модуля требуется установка зависимостей, например, pypng для генерации PNG файлов или pillow для более продвинутой работы с изображениями.
