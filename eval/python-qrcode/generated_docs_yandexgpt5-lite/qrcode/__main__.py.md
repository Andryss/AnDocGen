# Модуль `qrcode/__main__.py`


Модуль python-qrcode представляет собой генератор QR-кодов на чистом Python. Он может генерировать PNG-файлы и выводить QR-коды прямо в консоль. Для более продвинутого использования можно использовать класс QRCode с настраиваемыми параметрами.
