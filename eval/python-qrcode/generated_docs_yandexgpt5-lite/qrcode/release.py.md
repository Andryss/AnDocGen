# Модуль `qrcode/release.py`


Модуль предоставляет точки входа zest.releaser для использования при выпуске новых версий qrcode.

**Содержание:**

- [Функции](#функции)

## Функции

### `def update_manpage(data)`

Обновляет версию в документе manpage.

**Параметры:**

- `data` (`dict`) — Данные для обновления версии в manpage документе

**Примеры:**

Обновление версии в manpage документе

```python
update_manpage({'name': 'qrcode', 'new_version': 'new_version_value'})
```
