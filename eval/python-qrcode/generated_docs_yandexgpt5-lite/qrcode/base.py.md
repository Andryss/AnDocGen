# Модуль `qrcode/base.py`


Модуль содержит функции и классы для работы с QR-кодами, включая работу с полиномами и блоками RS.

**Содержание:**

- [Классы](#классы)
- [Функции](#функции)

## Классы

### `class Polynomial`

Класс для работы с полиномами.

**Назначение:**

Класс Polynomial предназначен для работы с полиномами, включая инициализацию, доступ к элементам, итерацию, определение длины, умножение и получение остатка от деления.

**Использование:**

Создайте экземпляр класса Polynomial и используйте методы __init__(num, shift) для инициализации, __getitem__(index) для доступа к элементам, __iter__() для итерации, __len__() для определения длины, __mul__(other) для умножения полинома на другой объект и __mod__(other) для получения остатка от деления.

#### Методы

##### `__getitem__(index)`

Возвращает элемент из внутреннего списка self.num по указанному индексу.

**Параметры:**

- `index` (`int`) — индекс элемента в списке self.num

**Возвращаемое значение:**

- `any` — элемент из списка self.num по указанному индексу

**Примеры:**

Возвращает элемент по индексу из внутреннего списка self.num

```python
return self.num[index]
```

Пример использования метода __getitem__ для получения элемента по индексу

```python
self.num[index]
```

##### `__init__(num, shift)`

Инициализирует объект Polynomial, проверяя параметр num на пустоту и дополняя его нулями в соответствии с параметром shift

**Параметры:**

- `num` (`list`) — Параметр num, который проверяется на пустоту и используется для инициализации атрибута self.num
- `shift` (`int`) — Параметр shift, который используется для дополнения списка num нулями

**Возвращаемое значение:**

- `N/A` — N/A

**Исключения:**

ValueError

**Примеры:**

Инициализация объекта Polynomial с параметрами num и shift

```python
def __init__(num, shift)
```

##### `__iter__()`

Возвращает итератор для элементов self.num

**Возвращаемое значение:**

- `iter` — итератор для элементов self.num

**Примеры:**

Возвращает итератор для элементов self.num

```python
return iter(self.num)
```

##### `__len__()`

Возвращает длину списка self.num

**Возвращаемое значение:**

- `int` — Целое число, равное длине списка self.num

**Примеры:**

Возвращает длину списка self.num

```python
return len(self.num)
```

Пример вызова метода __len__

```python
return len(self.num)
```

##### `__mul__(other)`

Умножает полином на другой объект.

**Параметры:**

- `other` (`N/A`) — Другой объект для умножения

**Возвращаемое значение:**

- `Polynomial` — Новый полином, являющийся результатом умножения

**Примеры:**

Умножить полином на другой объект

```python
Polynomial.__mul__(other)
```

**Смотрите также:**

def gexp(n), def glog(n)

##### `__mod__(other)`

Метод возвращает остаток от деления полинома на другой объект.

**Параметры:**

- `other` (`N/A`) — Другой объект для деления

**Возвращаемое значение:**

- `N/A` — Остаток от деления полинома на другой объект

**Примеры:**

Вычисление остатка от деления полинома на другой объект

```python
Polynomial.__mod__(other)
```

**Смотрите также:**

def gexp(n) — Возвращает значение из таблицы EXP_TABLE по заданному индексу; def glog(n) — Функция glog возвращает значение из таблицы LOG_TABLE, соответствующее аргументу n.

## Функции

### `def gexp(n)`

Возвращает значение из таблицы EXP_TABLE по заданному индексу.

**Параметры:**

- `n` (`int`) — Индекс в таблице EXP_TABLE

**Возвращаемое значение:**

- `N/A` — Значение, соответствующее индексу n % 255 в таблице EXP_TABLE

**Примеры:**

Возвращает значение из таблицы EXP_TABLE по индексу n % 255

```python
return EXP_TABLE[n % 255]
```

### `def glog(n)`

Функция glog возвращает значение из таблицы LOG_TABLE, соответствующее аргументу n. Если n меньше 1, возникает исключение ValueError.

**Параметры:**

- `n` (`int`) — Аргумент n используется для получения значения из таблицы LOG_TABLE. Если n меньше 1, возникает исключение ValueError.

**Возвращаемое значение:**

- `N/A` — Возвращает значение из таблицы LOG_TABLE, соответствующее аргументу n.

**Исключения:**

ValueError

**Граничные случаи:**

Если n меньше 1, возникает исключение ValueError.

**Примеры:**

Вызов функции glog с аргументом 1

```python
glog(1)
```

### `def rs_blocks(version, error_correction)`

Возвращает список блоков RS для заданной версии QR-кода и уровня коррекции ошибок.

**Параметры:**

- `version` (`int`) — Параметр для выбора версии QR-кода, целое число от 1 до 40
- `error_correction` (`constants.ERROR_CORRECT_L`) — Параметр для выбора уровня коррекции ошибок

**Возвращаемое значение:**

- `list` — Список блоков RS

**Исключения:**

ValueError

**Примеры:**

Вызов функции rs_blocks с версией 1 и уровнем коррекции ошибок ERROR_CORRECT_L

```python
rs_blocks(1, qrcode.constants.ERROR_CORRECT_L)
```
