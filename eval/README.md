# Eval

Внешние open-source проекты для апробации AnDocGen.

| Каталог | Проект | Описание |
|---------|--------|----------|
| `python-qrcode/` | [lincolnloop/python-qrcode](https://github.com/lincolnloop/python-qrcode) | Чистый Python-генератор QR-кодов с поддержкой PNG, SVG и консольного вывода. |
| `schedule/` | [dbader/schedule](https://github.com/dbader/schedule) | Планировщик задач с человекочитаемым синтаксисом для периодического запуска функций. |
| `cachetools/` | [tkem/cachetools](https://github.com/tkem/cachetools) | Расширенные коллекции и декораторы для кэширования (LRU, TTL и аналоги). |
| `humanize/` | [python-humanize/humanize](https://github.com/python-humanize/humanize) | Утилиты для «очеловечивания» чисел, дат, размеров файлов и списков с локализацией. |
